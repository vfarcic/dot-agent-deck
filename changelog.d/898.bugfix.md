## An empty `DOT_AGENT_DECK_STATE_DIR` no longer breaks daemon startup

`DOT_AGENT_DECK_STATE_DIR` overrides where the deck keeps its per-user state — the detached daemon's log and the lazy-spawn mutex. The override was honored whenever the variable was *present*, without checking that it held anything, so setting it to an empty value resolved the state directory to `""`: a relative empty path. That is not an exotic way to set a variable — a shell profile or CI config that exports it unconditionally produces exactly this, and so does `DOT_AGENT_DECK_STATE_DIR=` on a command line. The `$XDG_STATE_HOME` branch immediately below it has always guarded against an empty value; the override simply never got the same check.

On Unix the visible symptom was a failure to start rather than state written somewhere surprising, and the message did not lead anywhere useful. Before the lazy-spawn path joins anything onto the state directory it creates it and tightens it to owner-only, and that step ends in a `set_permissions("")` that fails with `ENOENT` — so the attach aborted reporting a not-found path, with nothing in the error naming the variable that produced it. Had that step succeeded, the spawn mutex and the daemon log would have been written relative to whatever directory the process happened to start in; the guard now forecloses both outcomes at the resolver instead.

An empty value is treated as unset and falls through to the rest of the documented chain — `$XDG_STATE_HOME/dot-agent-deck`, then `$HOME/.local/state/dot-agent-deck` on Unix, and `%LOCALAPPDATA%\dot-agent-deck` on Windows. The override is read before the platform split, so the one check covers both.

Nothing changes for a value that is actually set. Emptiness is the only thing checked — a non-empty override is still returned verbatim, relative paths included, with no canonicalization, existence check or absoluteness requirement added. The end-to-end test harness points this variable at its own scratch directory on every run, so that pass-through is load-bearing and was deliberately left exactly as it was.
