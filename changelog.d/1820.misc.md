## New OpenAI defaults for desktop voice control

OpenAI is retiring the models the desktop app's voice control used by default, starting with `gpt-5-mini` on 11 December 2026. Commands now default to `gpt-6-luna`, and OpenAI Speech now defaults to `gpt-transcribe`, which is faster than `whisper-1` and costs less per minute.

If your settings file names `gpt-5-mini` as the Commands model at OpenAI's endpoint, which earlier versions filled in whenever Commands was switched to OpenAI, the app now uses `gpt-6-luna` instead, and Settings → Voice shows it. A model you set at another endpoint, such as a gateway or a server on your computer, is used as written. A saved `whisper-1` Speech model is kept, and keeps working until OpenAI retires it on 26 February 2027.

With `gpt-transcribe`, the app can check only the number of words a reply has against the sound, because the model does not report when each word was spoken. Choose `whisper-1` or the speech container on your computer for the stricter checks.

See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice#settings--voice).
