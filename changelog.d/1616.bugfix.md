## Prompts with Windows or old Mac line breaks are submitted once

A prompt the deck typed into an agent could stop short of being sent when its lines were separated by anything other than a plain newline. A task file saved with Windows line endings (`dispatch --task-file`) was submitted, but the deck did not recognise it as submitted, typed the whole task into the agent's input box again while the agent was working on it, and finally marked the delivery as failed. A prompt whose lines were separated by a bare carriage return, or by a vertical tab, form feed or Unicode line or paragraph separator, sat in Claude Code's input box with "review and press Enter to send" until someone pressed Enter. The deck now sends every line break as a plain newline, so each of these prompts is submitted once.
