## A run's telemetry names every pull request it opened

With telemetry on, an `agent.run` span now carries `deck.pr.numbers`, every pull request the run saw, each once and in the order it first saw them, written as `,2054,2056,`. Before, a run that opened two pull requests named only the last one in `deck.pr.number`, so the first could not be joined to the run that made it. `deck.pr.number` is unchanged. To find the runs behind one pull request, filter on `deck.pr.numbers contains ,2054,`.

The telemetry page now also says plainly that an `agent.run` span's `duration_ms` is how long the agent's pane lived, waiting and idle time included, and shows how to measure the time an agent actually worked from its `agent.status` spans. See [Telemetry](https://agent-deck.devopstoolkit.ai/docs/telemetry.md).
