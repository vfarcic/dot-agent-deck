## Blocked-Worker Reports Arrive With the Idle-Worker Timeout Off

Turning off the "has not responded" report with `worker_response_timeout_minutes = 0` no longer also turns off the report that a delegated worker is blocked by a provider usage limit. An orchestrator now hears `⚠ delegated worker blocked by a provider usage limit` whatever the timeout is set to, so it can hand the task to another role or tell you instead of waiting on a worker that cannot continue. Setting the timeout to `0` still turns off only the idle-worker report.

See [Idle Workers & Notifications](https://agent-deck.devopstoolkit.ai/docs/idle-workers-and-notifications.md) for the reports and the settings that control them.
