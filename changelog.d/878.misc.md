## The OpenCode real-agent delegate test can pass again, and its readiness marker no longer carries a decorative glyph

`orchestration/delegate/015` — the real-agent test that proves a `clear = true` delegate reaches a live interactive OpenCode worker and that the worker visibly acts on it — could not pass at all against a current OpenCode, and failed in its *first* assertion rather than in anything it exists to cover. It waited for the literal `Ask anything...` with three ASCII periods while OpenCode paints `Ask anything…` with a single horizontal ellipsis. The wait underneath is a plain substring match, so the two could never meet: the test burned its full 120-second ceiling on runs where OpenCode had booted fine and was visibly sitting at its composer, then reported that the worker "never became visibly input-ready" and that this was "a boot/auth failure" — sending every reader to check credentials that were never the problem.

The readiness contract is now a set of markers matched any-of, and every member of it is required to be free of decorative glyphs. This test's marker is `Ask anything`: the part of the string that carries the meaning, with the decoration left out. Pasting in the new ellipsis would have been exactly as fragile as the old one and would have drifted again on the next upstream composer change; the set is any-of so a future rendering that is not a substring of this one can be added beside it rather than replacing something that still works elsewhere. The failure message no longer asserts a cause — it names what it looked for, says the run stopped in a precondition without delegating anything, and tells the reader which part of the dumped grid distinguishes an agent that never booted from a marker that has drifted.

Nothing in CI runs this lane, which is why an upstream UI string could break it silently for months, and the same drifted literal is corrected wherever it was quoted as a measurement — in the readiness-buffer derivations in the source and the adapter docs, and in the test catalog — with an explicit note that whatever eventually watches this boundary in the product must not match the trailing ellipsis either. The sibling Claude arm was unaffected: its marker (`? for shortcuts`) has no decorative glyph.

Verified by running the test on a real OpenCode: it passes in 29-37 seconds where it previously spent its full 123-second ceiling on the way to failing.
