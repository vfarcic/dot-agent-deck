## A product landing page at agent-deck.devopstoolkit.ai, and a docs site whose claims match the product

`agent-deck.devopstoolkit.ai` used to open on a Docusaurus docs home. It now opens on a product landing page: what Agent Deck is, what it looks like running, how to install it, and where to go next. The page was chosen from four candidate directions built with real content, and the three that lost were removed. Its navbar and footer are the docs' own, so nothing shifts when a visitor clicks through to `/docs`, and a closing band hands the visitor six specific documentation pages instead of a generic "read the docs" link. The page holds up at phone width (checked at 360px and 320px) and in both light and dark themes.

**The page now says what the product actually ships.** The desktop app was missing from the landing page entirely and now has its own section; it is described as an alpha with unsigned bundles for macOS and Linux and no Windows bundle yet, alongside the build provenance that does ship with the release. The agent list named two agents and now names all five the product supports — Claude Code, OpenCode, Pi, Codex and Devin. The Windows install tab pointed at a closed issue and now points at the open one ([#164](https://github.com/vfarcic/dot-agent-deck/issues/164)). The Linux install no longer hedges with "Homebrew (if available)", because the Homebrew formula covers both Linux architectures.

**Every link in the docs is readable in light mode.** The docs' link color measured 1.93:1 against a white background, below the WCAG AA minimum of 4.5:1, on every page. Links in light mode now use a darker teal (5.07:1); dark mode and the rest of the color scheme are unchanged.

**The screenshots are current.** Ten product images dated May or earlier were recaptured or removed. Two of them showed a maintainer's home directory path, and one of those also showed an unrelated project's internal orchestration config; that image is deleted and the other recaptured. A new capture backs the "walk away and come back" claim on the landing page, and the New Agent dialog image now shows the dialog as it looks today.

See the [Getting Started guide](https://agent-deck.devopstoolkit.ai/docs/getting-started) for the install paths the landing page links to.
