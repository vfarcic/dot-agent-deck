## A product landing page at agent-deck.devopstoolkit.ai, and one look across the whole site

`agent-deck.devopstoolkit.ai` used to open on a Docusaurus docs home. It now opens on a product landing page: what Agent Deck is, what it looks like running, how to install it, and where to go next. The page was chosen from four candidate directions built with real content, and the three that lost were removed. It holds up at phone width (checked at 360px and 320px) and in both light and dark themes.

**It leads with what the product does today.** The story the page tells is an escalation rather than a tour: open a pane — which can be a single agent, a full multi-agent orchestration, a dispatcher, or a scheduled task — watch every agent on its own live card, let one agent run the others, and send whole lines of work off into their own copies of the repository. Dispatching had no presence on the site's front door at all and now closes the story, with its own link in the closing band; orchestration is no longer buried behind a single mention. Workspace modes are on their way out ([#1199](https://github.com/vfarcic/dot-agent-deck/issues/1199)) and no longer appear on the page.

**`/` and `/docs` are one product now.** The landing page's colours used to be its own; they are now the site's, so the background, the text, the hairlines and the link colour stay put when you click through from the landing page into the documentation. The most visible part is dark mode, which moves from Docusaurus's default grey to the landing page's deeper near-black across every docs page. Only colours moved: the documentation's type, layout and components are untouched, and none of the landing page's gradients or device frames follow it in.

**Everything coloured in the docs is readable in light mode.** The docs' link colour measured 1.93:1 against a white background, below the WCAG AA minimum of 4.5:1, on every page. Links now measure 5.07:1, and the four other pieces of coloured text in the chrome — the selected sidebar item, the active navbar item, the active breadcrumb and the highlighted table-of-contents entry — were all below 2:1 and now clear AA too. Dark mode is unchanged.

**The page says what the product actually ships.** The desktop app was missing from the landing page entirely and now has its own section; it is described as an alpha with unsigned bundles for macOS and Linux and no Windows bundle yet, alongside the build provenance that does ship with the release. The agent list named two agents and now names all five the product supports — Claude Code, OpenCode, Pi, Codex and Devin. The Windows install tab pointed at a closed issue and now points at the open one ([#164](https://github.com/vfarcic/dot-agent-deck/issues/164)). The Linux install no longer hedges with "Homebrew (if available)", because the Homebrew formula covers both Linux architectures.

**The screenshots are current.** Ten product images dated May or earlier were recaptured or removed. Two of them showed a maintainer's home directory path, and one of those also showed an unrelated project's internal orchestration config; that image is deleted and the other recaptured. The New Agent dialog image now shows the dialog as it looks today.

See the [Getting Started guide](https://agent-deck.devopstoolkit.ai/docs/getting-started) for the install paths the landing page links to.
