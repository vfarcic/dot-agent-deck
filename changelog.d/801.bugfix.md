## The desktop app stops refusing decks it can talk to perfectly well

Connecting the desktop app to a deck used to compare the two builds' `git describe` stamps, and refuse on any difference the release digits did not excuse. `git describe` reports the nearest tag *reachable from your commit*, and the release workflow applies that tag **after** the content it names has landed — so a build made in between reported the previous release's version while being functionally the new one, and the app refused a deck whose source was byte-for-byte identical to its own. Measured on issue #801: `build mismatch: desktop is 0.38.0-gfa02054-dirty, daemon is 0.39.0-g1ea0fe7`, between two trees with no difference at all. The check was measuring where a tag sits in the commit history rather than what either build can do.

**It now classifies from the contract instead.** Each build declares the compatibility breaks it carries — one entry per `breaking` changelog fragment, written in the same commit as the change — and the handshake compares those two lists. Two builds of the same source always agree, whatever any tag says or has not said yet, so the everyday false refusal is gone: a branch build, a rebuild with an unsaved file, a release a patch or a minor apart, a build from a tarball with no git history at all. **Connect anyway** stays, and stays confirmation-gated, but it is now the rare path rather than the one you meet every day.

Two builds a real break *does* separate are still refused, and the refusal now says which break and which side is behind it rather than printing two commit hashes and leaving you to guess. That includes the case nothing could see before: a break where the wire shape never moved and only the meaning of a field changed. Those deliberately do not move the protocol version and they leave no trace in a version number, so the only thing that could ever detect one is the author's own declaration — which is now compiled into both binaries instead of living solely in a release note.

`PROTOCOL_VERSION` is untouched and still refuses first, for every deck, with nothing able to bypass it. A deck built before this change declares nothing, and connects: the declaration list starts empty here, so a build that predates it is at that starting point by definition.
