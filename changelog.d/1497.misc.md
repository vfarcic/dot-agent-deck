Agents' hooks honour `DOT_AGENT_DECK_BIN`: start an agent from an environment that sets it, and its hooks run that `dot-agent-deck` binary instead of the installed one, while every other agent keeps the installed one. On macOS and Linux the deck now writes Claude Code, Codex and Devin hook commands as `/bin/sh -c 'exec "${DOT_AGENT_DECK_BIN:-$0}" "$@"' <installed path> hook --agent <agent>`, and rewrites an existing entry for the same binary in place the next time it installs hooks. The OpenCode plugin and the Pi extension read the same variable. Windows hook commands are unchanged and do not honour it.
