## The docs describe each screen in words

The documentation pages no longer embed screenshots. Each page now says what you see on the screen it describes (labels, buttons and statuses, in the TUI and the desktop app), so an agent reading the docs with `dot-agent-deck docs` or from the site gets the same information as a person looking at a picture. The installation guide and the website's landing page keep their screenshots, refreshed to the current app.

Some pages still said the desktop app shows a working agent as **running**. They now use the words the desktop app shows, which are the TUI's: **Thinking**, **Working** or **Compacting**.
