## A subagent that ends after a permission request no longer leaves its parent card waiting for input

When a Claude Code or Codex subagent raised a permission request, the parent agent's card went to Needs Input, and if that subagent then stopped or failed without the call ever running, nothing lifted it: the card kept asking for input that was no longer wanted, and an orchestrator that had delegated to the agent could be told the worker was waiting.

The end of the subagent that raised the prompt now ends the wait. The card goes back to Idle when the main agent's turn had already finished, and to Thinking when it is still running; a subagent never turns the card Working, Error or Blocked. A wait the main agent raised itself, or one another subagent is still holding, is left as it is. Devin, OpenCode and Pi report no subagent marker the deck reads, so their cards are unchanged.

See [Session management](https://agent-deck.devopstoolkit.ai/docs/session-management).
