## Start a Daemon From the Desktop App, on This Machine or a Remote Host

The desktop app can now start a daemon that is not running, without leaving the app and without the `experimental` flag. When a daemon's section on the Dashboard says **Daemon disconnected**, it says why and offers one button: **Start daemon** when no daemon is running there, or **Reconnect** when a daemon is running but the app is not connected to it, or when the app cannot tell, for example because the host cannot be reached.

**Start daemon** works for the daemon on this machine and for a remote one, which the app starts over ssh with that daemon's settings, so the deck only needs to be installed there (`dot-agent-deck remote add`). The app asks first, naming the machine the daemon will start on, and the section connects once the daemon answers. When a start fails, the section says why in plain terms: the host cannot be reached, ssh could not log in, the deck is not installed there, or the daemon started but did not answer where the app looks for it.

See [Daemons → Start a daemon from the app](https://agent-deck.devopstoolkit.ai/docs/desktop/daemons.md) for details.
