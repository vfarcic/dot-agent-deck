## Docs site: readable text on the teal accent in both themes

In the light theme the documentation site's accent teal is now the darker `#0a7c73` that its links already used, instead of the bright `#4ecdc4`, which white text could not be read against (1.93:1). Primary buttons, such as the "Try again" button on the site's error page, now have white text on that teal at 5.07:1, and the page-load progress bar and the code-block word-wrap toggle use the same colour. The dark theme keeps the bright teal, and a primary badge there now uses dark text (10.01:1) instead of white.
