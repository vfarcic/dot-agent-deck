## Directory names shown whole in the New agent dialog with voice on

With voice on, the desktop app's **New agent** dialog no longer cuts a few long directory names short while most of the list stands empty. A short list now uses only the columns it needs, so its names have the list's whole width; a long one still fills every column and splits into pages as before. The Mode chips likewise share the Mode row's width rather than leaving an empty column beside them. A name that is still cut short shows in full when you hover over it. See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice).
