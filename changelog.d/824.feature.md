## Saved prompts follow the daemon

The desktop app's **Prompts** library is now in the rail for everyone, no longer behind the `experimental` flag, and opens over the Daemons screen. It belongs to the daemon chosen in the Dashboard's **Daemon** selector instead of the computer the app runs on. Every desktop app connected to that daemon shows the same saved prompts, including one that reaches it from another machine, and each daemon has its own. The library says it is the daemon's, saves your edits there as you type, and asks you to choose one daemon when **All daemons** is selected.

Prompts you saved in an earlier version move into the first daemon you select that keeps prompts, and the library says how many moved. A prompt the daemon already holds is never overwritten. A prompt longer than a daemon keeps stays on this computer, and the library names it. If the daemon refuses the move, your prompts stay on this computer and the move is tried again the next time the library loads. With a daemon from an earlier release selected, the library is kept on this computer as before.

Saved prompts are inserted from the Orchestrations editor's **Insert saved prompt**, which is still behind the `experimental` flag. See [Saved prompts](https://agent-deck.devopstoolkit.ai/docs/desktop/index.md).
