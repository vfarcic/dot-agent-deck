## Saved prompts follow the daemon (experimental)

The desktop app's **Prompts** library now belongs to the daemon you have selected instead of the computer the app runs on. Every desktop app connected to that daemon shows the same saved prompts, including one that reaches it from another machine, and each daemon has its own library. The library says it is the daemon's, saves your edits there as you type, and shows nothing until you choose one daemon when **All daemons** is selected.

Prompts you saved in an earlier version move into the first daemon you select that keeps prompts, and the library says how many moved. A prompt the daemon already holds is never overwritten. A prompt longer than a daemon keeps stays on this computer, and the library names it. If the daemon refuses the move, your prompts stay on this computer and the move is tried again the next time the library loads. With a daemon from an earlier release selected, the library is kept on this computer as before.

The Prompts library is behind the `experimental` flag (`DOT_AGENT_DECK_EXPERIMENTAL=1` in the app's environment). See [The desktop app](https://agent-deck.devopstoolkit.ai/docs/desktop/index.md).
