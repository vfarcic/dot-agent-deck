## Refused Agents Are Told When You Approve or Decline

When the deck refuses an agent's `dispatch`, `delegate`, `pane restart` or `pane spawn` because its orchestration is not approved, the agent now hears your answer. Approve the review the deck opened, in the TUI or the desktop app, or run `dot-agent-deck trust approve` from a terminal, and each agent that was refused gets a notice in its inbox saying the orchestration was approved and to retry now. Decline it and they are told you declined, so they stop waiting. If the project's `.dot-agent-deck.toml` changes before you answer, they are told the request closed, so they can try again and be asked about the new text. You no longer have to tell an agent "I approved it, retry".

Approving still starts nothing by itself: the agent decides whether it still needs to retry. The refusal an agent receives now says it will be told, so it waits for the notice instead of retrying blindly. Schedules are unchanged and run at their next fire.

See [Approving Project Commands](https://agent-deck.devopstoolkit.ai/docs/project-trust.md) for the review and what each answer does.
