## OpenCode 2 cards no longer count OpenCode's own server as a background command

An OpenCode 2 agent started by the deck showed `Background: 1 command` on its card even when it had started nothing, because the card counted OpenCode's own server as a command left running. The card now counts only the commands the agent actually runs in the background, in the TUI and the desktop app alike, so an OpenCode 2 agent no longer reads **Waiting** after its first turn for a command that does not exist.
