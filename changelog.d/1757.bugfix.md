## OpenCode 2 cards no longer count OpenCode's own server as a background command

An OpenCode 2 agent started by the deck showed `Background: 1 command` on its card even when it had started nothing, because the card counted OpenCode's own server as a command left running. The card no longer counts that server once the deck has recognised it, a few seconds after OpenCode starts, in the TUI and the desktop app alike, so an OpenCode 2 agent's card does not stay on **Waiting** after its first turn for a command it never ran. When the deck cannot tell which OpenCode version a pane runs (which can happen when a wrapper script starts it), the server is still counted.
