## Plain letters for the `Ctrl` commands in command mode

In the TUI's command mode you can now drop the `Ctrl`: `d` goes back to the pane, `n` starts a new agent, `w` closes (after its confirmation), `t` toggles the layout, `z` zooms and `e` toggles the experimental command-entry lock, each doing exactly what its `Ctrl+` chord does. When the selected card is waiting for a permission answer, `n` still denies it. `l` stays next tab and there is no plain `c`. The `Ctrl+` chords keep working everywhere they did, and while you type in a pane every letter still goes to the program.

A letter works only while its command is on its default key and no other command uses that letter, so your own remaps win. The help overlay lists `d`, `n`, `w`, `t` and `z` beside their chords, for example `n / Ctrl+n`, and the bottom bar shows `d`, `n`, `w` and `t`. The desktop app's shortcuts are unchanged.

See [Plain letters in command mode](https://agent-deck.devopstoolkit.ai/docs/keyboard-shortcuts.md#plain-letters-in-command-mode).
