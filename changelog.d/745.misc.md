## Agent overview screen for the desktop preview (fixture-only)

The desktop preview gains a fleet-overview screen: every agent a daemon owns, grouped the way the daemon already groups them — one card per orchestration with its roles in role order and its coordinator marked, one per mode tab, one for standalone panes — with status, agent type, working directory, active tool and tool count, and no terminals. It answers "what is running right now" at fifteen agents, which the existing control deck does not: that deck renders every agent with a live embedded terminal, so it degrades exactly when a fleet gets large enough to need an index.

The screen shows only what the daemon genuinely reports. Model, token, cost, context-window, git-branch, attempt-count and session-duration columns are deliberately absent rather than shown as `Unavailable`, because none of them exists anywhere in daemon state; a type-level projection makes reading one of those fields on this screen a compile error. Daemon-supplied text — display names, directories, tool details — is stripped of control and bidirectional formatting characters before rendering, so a name carrying a `U+202E` cannot visually reverse itself or swallow the markers beside it on a screen whose whole job is telling agents apart.

This first iteration is **reachable only in fixture mode**, via the new Overview button in the left rail: `pnpm dev`, then `?fixture=1&state=crowded` for a fifteen-agent fleet, or `state=empty`, `state=disconnected` and `state=error` for the first-run, unreachable-daemon and incompatible-daemon states. The gate is deliberate. Attaching a terminal is currently driven by the daemon snapshot rather than by what is on screen, so a live overview would still hold one socket and one scrollback replay per agent behind a screen showing none — the exact cost the screen exists to remove. The gate lifts when attach becomes demand-driven.

Developer notes are in `docs/develop/desktop-gui.md`; the plan, the column decision and the staging are in [PRD #745](https://github.com/vfarcic/dot-agent-deck/issues/745).
