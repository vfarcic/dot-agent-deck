## Copying Text Out of an Agent's Terminal Works in the Desktop App

Selecting text in an agent's terminal in the desktop app and copying it did not put anything on the clipboard. Select the text with the mouse and press `Ctrl+Shift+C` on Linux and Windows, or `⌘C` on macOS, and the selection is copied. The copy key is never sent to the agent, and plain `Ctrl+C` still interrupts the agent as before, even while text is selected.

See The agent pane in [Dashboard](https://agent-deck.devopstoolkit.ai/docs/desktop/dashboard.md).
