## Agent Hooks Repaired Before an Agent Starts

A Claude Code agent now reports its status even when Claude Code was set up after the deck started, or when its hooks call a copy of `dot-agent-deck` you have since deleted. Before, such an agent stayed on a coarse status until you restarted the deck or ran `dot-agent-deck hooks refresh`.

Each time the deck starts a Claude Code, Codex or Devin agent, from the TUI, the desktop app, a scheduled task or a dispatch, it checks that agent's hooks first and installs or repairs them when they call no copy of the deck or a deleted one. Hooks that already call an installed copy are left exactly as they are, so starting an agent does not rewrite your settings file. If the deck cannot read or write the file, for example because it is not valid JSON, it leaves the file as it was and the agent starts without the deck's hooks; `dot-agent-deck hooks refresh` says why.

See [Installation → Agent hooks](https://agent-deck.devopstoolkit.ai/docs/installation.md) for when the deck installs and repairs hooks.
