## Pre-release Claude Code and Codex builds now get the doorbell

A pre-release build of Claude Code or Codex, one whose version carries a suffix such as `0.172.0-alpha.2` or `2.1.330-beta.1`, used to get no doorbell and no input-box check. The deck didn't read its version from the start-up screen, so its card said `waiting for the agent to fetch it. Send it a prompt.`, the deck log named `unknown_release`, and messages waited for your next prompt.

The deck now reads those versions and treats a pre-release build like any other release of its agent. It checks the input box and types the doorbell the same way, in the TUI and in the desktop app. A pre-release is the build most likely to have changed its screen or keys, so if the doorbell misbehaves on one, turn it off for that agent as described in [Configuration](https://agent-deck.devopstoolkit.ai/docs/configuration.md).

## The Codex doorbell no longer stalls when its line wraps after a slash

The doorbell line names the path of the deck's own program. When that path made Codex wrap the line right after a `/`, the deck didn't recognise its own line in Codex's input box. It stopped without pressing Enter, the card said the deck's notice might be in the agent's input, and the message waited for you. The deck now reads a line Codex wrapped after a `/` as its own and finishes the delivery.
