## The desktop dashboard no longer hides daemons and orchestrations while voice is on

With voice on, a dashboard taller than the window used to be split into pages, and only the page showing was drawn, so with **All daemons** selected a second orchestration or the daemons with no agents could be missing, with only a small "Page 1 of N" beside the title to say so. The dashboard now looks the same with voice on as with voice off: nothing is left out, and it scrolls as usual with the mouse, trackpad or keyboard. Voice only adds the row numbers, which now count once down the whole dashboard, so "agent 7" means the same row wherever the dashboard is scrolled. Saying the number of a row you have scrolled past opens that agent and scrolls its row back into view.

To scroll by voice, say "scroll down" or "scroll up" to move about one window, or "scroll to the top" / "scroll to the bottom" to go to either end; "next page", "previous page", "page down" and "page up" scroll the dashboard too. The New agent dialog's directories and modes and the Daemons screen's tiles are still shown a page at a time while voice is on. See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice#scrolling-the-dashboard).
