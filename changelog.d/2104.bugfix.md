## Quieter daemon log when agents are closed or restarted

Closing an agent, or restarting a role between delegations, no longer leaves a warning in the daemon log for each one. Claude Code in particular reports one last status as it shuts down, and that report arrives just after the deck has let the agent go. The deck still ignores that late report, but now records it as routine debug detail rather than as a warning. Any other status report the deck refuses is still logged as a warning.
