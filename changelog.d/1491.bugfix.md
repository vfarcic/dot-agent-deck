## Switch to All daemons by voice in the desktop app

Saying "select all daemons", "switch to all daemons", "show all daemons" or "switch daemon to all" now switches the Dashboard's **Daemon** selector to **All daemons**, exactly as clicking it does, where the app used to answer that no daemon matches. Saying it while **All daemons** is already chosen changes nothing and says so. While voice is on and the selector's menu is open, **All daemons** now shows a number like the other entries, so "one" chooses it too. Asking to show everything still opens the agent dashboard without changing which daemons it shows. See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice).
