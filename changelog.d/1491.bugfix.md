## Switch to All daemons by voice in the desktop app

Saying "select all daemons", "switch to all daemons", "show all daemons" or "switch daemon to all" now switches the Dashboard's **Daemon** selector to **All daemons**, exactly as clicking it does, where the app used to answer that no daemon matches. Saying it while **All daemons** is already chosen changes nothing and says so. While voice is on and the selector's menu is open, **All daemons** now shows a number like the other entries, so "one" chooses it too. Asking to show everything still opens the agent dashboard without changing which daemons it shows.

Switching daemons by voice also no longer depends on the transcription spelling a daemon's name exactly. "Select mini PC, demon" now switches to a daemon named `minipc` from the Dashboard's **Daemon** selector and chooses it in the New agent dialog's **Daemon** field, where it used to answer that no daemon matches. Capitals, spaces and the punctuation the transcription adds no longer matter, and "daemon" transcribed as "demon" is understood. See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice).
