## Dispatch: a single-agent unit is told more clearly to send its result back

A unit started with `dot-agent-deck dispatch --single` could finish its task and leave the answer only in its own conversation, so the agent or person that dispatched it never received the result. Single-agent units are now instructed more clearly to send their result back to whoever dispatched them, so they report back more reliably. If a unit still ends without reporting, open its pane and ask it to send its report.
