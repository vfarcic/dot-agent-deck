A shell command you interrupt with Escape or Ctrl+C no longer keeps its `agent.operation` span open until the agent's run ends. Claude Code reports no end for an interrupted command, so the deck now ends its span at the key you pressed, once the agent's next turn ends, and marks it `deck.operation.end=interrupted`. Any other command an agent leaves without an end when its turn finishes now ends with that turn, marked `turn_end`, instead of `run_end`. Summed command time no longer counts the minutes or hours between an interrupt and the run's end. `deck.telemetry.schema_version` is now `5`, so you can keep data recorded before and after this change apart.
