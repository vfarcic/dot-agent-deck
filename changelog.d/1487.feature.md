## Upgrade Remote Daemons From the Desktop App, and Restart Them From the CLI

The desktop app can now upgrade a remote daemon. When a remote daemon runs an older release than the app, its section on the Dashboard shows an **Upgrade** button, and so does the **Incompatible daemon** note, which until now offered at most **Connect anyway**. Upgrade installs the app's version on that machine and restarts the daemon onto it, showing each step and then what happened, without leaving the app.

`dot-agent-deck remote upgrade <name>` now restarts the remote's daemon onto the new release as well as installing it, so agents you start afterwards run the new version straight away instead of after your next `connect`. `connect`'s "Upgrade and connect?" offer does the same. A new `--json` flag prints the result as JSON for scripts.

No upgrade stops a running agent without asking. When agents or orchestration roles are running on the daemon, the CLI, `connect` and the desktop app all list every one the restart would stop and ask: **Restart now** stops exactly those, and **Keep current daemon** stops nothing, leaving the new release installed for the daemon's next restart. With nothing running, the daemon restarts without asking. With no terminal to ask on, `remote upgrade` installs and keeps the running daemon.

A daemon started by an earlier release cannot be asked to restart. The new release is still installed, and the result says how to switch: run `dot-agent-deck connect <name>` and accept its restart prompt. A daemon run as a systemd user service comes back on the new release by itself, as long as its unit keeps `Restart=on-failure`. Installing an older release with `--version` leaves the daemon running and says how to switch.

With the `experimental` flag on, **Replace daemon** on the Daemons screen works the same way for the daemon on this machine: it is no longer withheld while agents are running, and asks before stopping them instead.

See [Remote Environments → Upgrade a remote](https://agent-deck.devopstoolkit.ai/docs/remote-environments.md) and [Daemons → Upgrade a remote daemon](https://agent-deck.devopstoolkit.ai/docs/desktop/daemons.md) for details.
