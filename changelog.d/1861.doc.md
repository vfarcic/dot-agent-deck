## Host figures are the machine's, not an agent's

The docs for the **Host of this deck** figures, which the TUI's host overlay and the desktop app's **Host** button open, now say plainly that they describe the whole machine the deck runs on, including everything else running there, not any one agent. Neither client shows figures per agent, so the page now points to the collector, which sends each agent run's CPU time and memory, and each worktree's disk use, to your telemetry backend on Linux.

See [Session Management → Check the machine a deck runs on](https://agent-deck.devopstoolkit.ai/docs/session-management.md#check-the-machine-a-deck-runs-on) and [Telemetry → CPU, memory and disk per run](https://agent-deck.devopstoolkit.ai/docs/telemetry.md#cpu-memory-and-disk-per-run).
