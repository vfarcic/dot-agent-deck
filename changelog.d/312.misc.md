## The stacked/tiled layout toggle (`Ctrl+t`) is removed

The TUI no longer has a layout toggle. The pane column always shows the focused agent's pane at full height, on the dashboard and on an orchestration tab alike, which was already the default. Focusing another card shows its pane instead, and `Ctrl+z` (or `z` in command mode) still gives the focused pane the whole frame.

`Ctrl+t`, plain `t` in command mode and the `[Toggle Layout Ctrl+T]` button are gone, so `Ctrl+t` now reaches the program in the pane. A `keybindings.toml` that still sets `toggle_layout` keeps loading: the TUI prints a warning that the line is ignored because the toggle was removed, and you can delete it.

See [Keyboard Shortcuts](https://agent-deck.devopstoolkit.ai/docs/keyboard-shortcuts.md).
