## Fast typing into a desktop agent terminal no longer reorders characters

Each keystroke typed into an agent's terminal in the desktop app was sent to the deck as a separate request, and two requests in flight at once could be written to the agent in either order. Typing quickly could therefore deliver characters to the agent out of order — `echo dad-driver` arriving as `echo dadd-river`. The desktop app now sends each terminal's input one write at a time, in the order it was typed.
