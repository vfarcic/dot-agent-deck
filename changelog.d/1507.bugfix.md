## The TUI Lists Agents in the Order They Were Created

The TUI dashboard lists agents in the order they were created again, the same order the desktop app shows. Agents created from the desktop app, started with `dispatch` or started by a schedule used to appear in an arbitrary order that could change between restarts, so a dispatcher created first was not necessarily at the top. They now take their place by creation time alongside agents created from the TUI. An orchestration tab still lists its roles in the order the orchestration defines them.
