## Several voice commands in one sentence

The desktop app's voice control now takes up to three commands in one sentence, one after another: "open the overview and then the tester", "show the dashboard, then open the reviewer", or, in the New agent form, "make it a dispatcher, use codex and name it triage bot". Until now one sentence ran at most one command.

Each part is checked on its own words, on the screen the parts before it would leave you on, before anything runs; if any part could not run, nothing runs and the row says which part and why. If a part cannot run when its turn comes, the chain stops there and the row says which parts ran, so nothing is left half done without saying so. When every part moved the view, one **Undo** puts back the screen you started from. Starting a new agent, sending a prompt, typing into an agent and the other requests that must be said on their own are never combined with other commands, and a sentence with "or", "not", "instead" or "rather than" in it is always one command.

See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice.md#several-commands-in-one-sentence).
