## OpenCode 2.3 agents reach Idle again

With OpenCode 2.3, an OpenCode agent's card stopped reaching **Idle** once the agent had run its first shell command. It stayed on **Waiting** with `Background: 1 command` even when nothing was running, so a delegate or message waiting for the agent to go idle was held back.

The deck no longer counts OpenCode 2.3's own helper process as a background command. Commands the agent really leaves running after its turn, including ones it runs in the background, still show on the `Background:` line until they finish. OpenCode 2.2 is unaffected either way.
