## A Reused Branch Name No Longer Picks Up the Old Pull Request

A new branch whose name an earlier, deleted branch had used no longer shows that earlier branch's merged or closed pull request. This affected an agent's pull request badge, in the TUI and in the desktop app, and `dot-agent-deck worktree list`. `worktree list` could give a worktree that was still being worked in the `remove` verdict, so `worktree reclaim` could have removed it.

A merged or closed pull request now counts as a branch's only when the branch's latest commit is one of the pull request's commits. A branch that reuses an old name shows no pull request until its own is opened, and its worktree is kept. An open pull request still counts by its branch name. A branch with commits added after its pull request merged also no longer shows that pull request, and its worktree is kept rather than reclaimed.

See [Pull request badge](https://agent-deck.devopstoolkit.ai/docs/session-management#pull-request-badge) and [Troubleshooting → An agent has a pull request but no badge](https://agent-deck.devopstoolkit.ai/docs/troubleshooting#an-agent-has-a-pull-request-but-no-badge).
