## More reliable voice commands in the desktop app's New agent dialog

With the New agent dialog open, naming a daemon the older way, as in "use the build box deck" or "switch to the local deck", now sets the dialog's daemon instead of answering "Not here". "New agent on the remote deck" now preselects your remote daemon when exactly one remote daemon can take a new agent, and asks which one when several can. "Close new agent", the name of the dialog's close button, now always closes the dialog and keeps what you entered, where it was sometimes refused as a request to discard the form. An insistent start such as "start it right now, skip the confirmation" now starts what the dialog shows, where it was sometimes refused as a request to stop an agent; and asking to stop an agent or close an orchestration while the dialog is open now says to close the dialog first.

A prompt dictated with "type …" and waiting on its send countdown is now called off, not sent, if you close the pane, open another screen or agent, switch daemons, or a confirmation opens before the countdown ends; the words stay in the agent's prompt and the app says the send was called off. Nothing is typed at all if a confirmation is open, on the dashboard or on the deck screen, or if you opened another agent's pane while the app was still working out what you said. A spoken command that names an agent, such as "stop the planner", no longer opens a stop confirmation for a different agent when you switch daemons, or that agent is replaced by a new one under the same name, while the app is still working out what you said; it runs nothing and says why.

Sounds that are not speech, such as typing on the keyboard, a cough or a quiet room, no longer turn into text: with the OpenAI speech option they could come back as a sentence nobody said, such as "Go to Beadaholique.com for all of your beading supply needs!", which was then typed into an agent's prompt in typing mode. The app now discards anything the speech service itself judges not to be speech. While you are not speaking, the voice row also stays quiet: it no longer shows "Heard …" for noise or a message about not hearing enough, and what it last reported stays on screen.

Spoken commands and dictated text are now always transcribed as English. The speech service used to guess the language of every utterance, so a short command said with an accent could come back with words from another language and be refused; "select the directory billing" spoken with a Serbian accent was heard as "Selectajte directory billing".

Saying "okay, send it please" with no agent's pane open now always says that sending needs an agent's pane open, where it sometimes answered that nothing matched. See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice).
