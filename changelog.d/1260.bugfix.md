## More reliable voice commands in the desktop app's New agent dialog

With the New agent dialog open, naming a daemon the older way, as in "use the build box deck" or "switch to the local deck", now sets the dialog's daemon instead of answering "Not here". "New agent on the remote deck" now preselects your remote daemon when exactly one remote daemon can take a new agent, and asks which one when several can. "Close new agent", the name of the dialog's close button, now always closes the dialog and keeps what you entered, where it was sometimes refused as a request to discard the form.

Saying "okay, send it please" with no agent's pane open now always says that sending needs an agent's pane open, where it sometimes answered that nothing matched. See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice).
