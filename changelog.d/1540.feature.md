## The Last Command Is Shared Between the TUI and the Desktop App

When no `default_command` is set, the **Command** field of the TUI's `Ctrl+n` New Agent form and of the desktop app's **New agent** dialog is now pre-filled with the last command started from either of them on that deck. The deck remembers it on its own host, so the desktop app no longer forgets it when you restart the app, and a command you start from one client is offered by the other. Each deck remembers its own last command.

When the TUI attaches to a deck that has no remembered command yet, it hands that deck the command the TUI last started, so a deck can start out offering a command first used on another. A deck from an earlier release keeps the previous behaviour: the TUI remembers its own last command and the desktop app remembers one per deck until it quits.

See [Set the command new agents start with](https://agent-deck.devopstoolkit.ai/docs/configuration.md#set-the-command-new-agents-start-with).
