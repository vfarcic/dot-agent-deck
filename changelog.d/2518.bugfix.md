## Readable Review Project Commands Prompt on Light Terminals

The TUI's **Review project commands** prompt is now readable on a light terminal theme. It used to draw the commands and prompts you are asked to approve in white, and their labels in light gray, so on a light background the text that decides the approval nearly disappeared. The values now use your terminal's own text colour and the labels a faded version of it, so both stay readable on light and dark themes and the values still stand out from their labels.
