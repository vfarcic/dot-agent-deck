## Voice: "see only the tester" opens that agent again

In the desktop app, saying "see only" followed by one agent's name or role, such as "see only the tester", opens that agent's pane, as the voice docs describe. Most of the time it was filtering the agent dashboard to that name instead. Naming several agents or a category, such as "show only the dispatchers", still filters the dashboard.

See [Voice](https://agent-deck.devopstoolkit.ai/docs/desktop/voice.md).
