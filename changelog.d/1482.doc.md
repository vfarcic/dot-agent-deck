## Docs no longer describe workspace modes as a current feature

The desktop app pages no longer list workspace modes as something the TUI has and the app lacks, and [New Agent](https://agent-deck.devopstoolkit.ai/docs/desktop/new-agent.md) now says it offers the same kinds of start as the TUI's `Ctrl+n` form. Workspace modes were removed from both clients in 0.44.0. [Dashboard](https://agent-deck.devopstoolkit.ai/docs/desktop/dashboard.md) now explains that a **MODE TAB** group appears only while an agent started in a workspace mode by a release before 0.44.0 is still running.

The help-overlay screenshot on [Keyboard Shortcuts](https://agent-deck.devopstoolkit.ai/docs/keyboard-shortcuts.md) has been retaken from the current TUI, so it no longer shows a Mode Tab section. `daemon status` on [Installation](https://agent-deck.devopstoolkit.ai/docs/installation.md) and the Codex prompt note on [Troubleshooting](https://agent-deck.devopstoolkit.ai/docs/troubleshooting.md) no longer use workspace modes as their examples.
