## Project Paths With Unusual Characters No Longer Alter the Configuration Request

When you ask an agent to generate or update a project's `.dot-agent-deck.toml`, from the TUI or the desktop app, the request the deck sends names the project directory. A directory whose name held a backtick, a line break, an invisible character or text that reads like a deck message could change what the request seemed to say, adding headings or lines the deck never wrote.

Such a path is now written as `<project-dir>` throughout the request, and the request opens by giving the real path once as an escaped JSON string, which the agent decodes and uses as a single argument. Requests for ordinary paths, spaces and punctuation included, are unchanged.
