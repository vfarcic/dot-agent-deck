## Dispatched single units run the way their dispatcher does

A unit started with `dot-agent-deck dispatch <name> --single` now runs the same command as the dispatcher agent that asked for it, in the unit's own copy of the repository, and as the same agent. A dispatcher you started as `devbox run agent` gets units started as `devbox run agent`, so they run inside devbox as the dispatcher does. Before, every single unit started as your configured `default_command`, or `claude`, outside that environment, and a build that needed a devbox-provided tool failed in the unit while working in the dispatcher.

A Codex, OpenCode, Pi or Devin dispatcher now gets single units of its own agent rather than Claude Code ones. A dispatcher started with no command (your shell) still gets `default_command`, or `claude`, and scheduled runs are unchanged.

See the [`dispatch` reference](https://agent-deck.devopstoolkit.ai/docs/dispatcher-mode#dispatch-reference).
