## Codex Cards Show What Codex Is Doing

A Codex card no longer reads **Working** while Codex is doing nothing. A freshly started Codex now shows **Idle** until you send it a prompt, and goes back to **Idle** when its turn ends instead of returning to **Working** a moment later. While its turn runs, the card follows Codex the way a Claude Code card follows Claude Code: **Thinking** while it reasons, **Working** with the command it is running, and **Needs Input** while a permission prompt is on screen. In the desktop app's Dashboard the same Codex now reads **waiting** while it is idle, rather than **running**.

When the deck could not get Codex to trust its hooks, the card can only tell whether Codex's screen is changing. It now shows **Thinking** while Codex is drawing and **Idle** once the screen has been still for about three seconds, instead of **Working** for as long as Codex runs. In that case it shows no tool, no prompt and no **Needs Input**. See [Session Management](https://agent-deck.devopstoolkit.ai/docs/session-management#which-agents-report-which-status) for what a Codex card can report, and [Troubleshooting](https://agent-deck.devopstoolkit.ai/docs/troubleshooting#codex-events-not-showing) for getting its hooks trusted.

An OpenCode card whose turn the provider rejected now stays on **Error** (desktop: **failed**) until you send the next prompt. It used to switch to **Idle** a moment after the failure, so the failure was easy to miss. Interrupting OpenCode yourself still leaves the card **Idle**.
