## A project logo, used as the desktop app icon, the docs logo and the favicon

Agent Deck has one mark now: a stack of three terminal windows fanning out, in the docs site's teal and violet. It replaces three unrelated placeholders — the desktop app's cream "AD" icon, the "AD" badge at the top of the desktop app's rail, and the teal terminal outline in the docs navbar — and appears at the top of the README.

**The desktop app ships a full platform icon set** for the first time: a macOS `.icns` (there was none before), the Windows `.ico`, and the Linux PNG sizes, all generated from the same source.

**The docs site has a favicon.** Its configuration pointed at `img/favicon.ico`, which did not exist, so every page requested a favicon that returned a 404 and browsers showed a generic tab icon.
