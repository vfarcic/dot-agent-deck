## Cards Stay Idle After a Turn and Show the Work Still Running

When an agent whose hooks report to the deck ends its turn but leaves a command running in the background, its card no longer turns back to **Working** for as long as that command runs, which could be forever for a command that never exits. The card stays **Idle**, and a line under it says what the agent left running and for how long, for example `Background: 2 commands, 1 subagent · 3h 12m`. Subagents count too: a subagent that keeps working after the main agent has answered no longer leaves the card looking finished. The line goes away when the last of that work ends, so a command that has been running for hours is easy to spot and stop from the agent's pane.

The TUI shows the line on the card, and the desktop app in the agent's pane and on its tile on the Daemons screen, in the same words. Claude Code and Codex report background commands and subagents; OpenCode, Pi and Devin report background commands only. On Windows no background commands are counted. A TUI or desktop app older than the daemon does not show the line and can still show such a card as **Working**, so update both along with the daemon.

See [Session Management → Work left running after a turn](https://agent-deck.devopstoolkit.ai/docs/session-management.md#work-left-running-after-a-turn).
