## The desktop app tells an idle agent from one that needs you

The desktop app now shows an agent waiting for your answer as **needs input** and an agent that finished its turn as **idle**, the same two states the TUI shows as Needs Input and Idle. Before, both read **waiting**, so an agent that was simply done, for example while a background subagent it launched kept working, looked like it was waiting on you. The change covers the dashboard's rows and group counts, the agent tiles, the agent pane, and the header counters, where **NEEDS INPUT** and **IDLE** replace **WAITING**. An agent that needs input keeps the amber colour **waiting** had, and an idle one is drawn in a neutral grey. The dashboard filter's status now reads **Needs input**, and voice still understands "waiting for input".

See [Statuses](https://agent-deck.devopstoolkit.ai/docs/desktop/dashboard.md#statuses).
