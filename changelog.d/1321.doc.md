## The docs now cover the desktop app as well as the TUI

The docs site used to describe the terminal UI only. It now presents the TUI and the desktop app as two clients of the same daemon. The sidebar is grouped into what both clients do, what only the TUI does and what only the desktop app does; no page moved, so existing links still work. Where a common flow differs between the clients, the page shows it in **TUI** and **Desktop** tabs, and the tab you pick is remembered across the site.

New [Desktop app](https://agent-deck.devopstoolkit.ai/docs/desktop) pages cover the Dashboard, New agent, daemons (including remote ones), Settings and voice control. They list which desktop screens are hidden behind the `experimental` flag and explain that the app reads the flag from its own environment only, once at startup. [Installation](https://agent-deck.devopstoolkit.ai/docs/installation#desktop-app) now covers the desktop downloads: which file to get for your platform, how to install and first launch it, and how the app gets a daemon. The app connects to a running daemon and does not start one, so the page shows how to run one with the TUI or `dot-agent-deck daemon serve`, and how the daemon's 30-second idle shutdown applies. The home page presents both clients.
