## Interrupt, clear and scratch an agent's prompt by voice

In the desktop app's typing mode you can now say "interrupt" (or "stop") to stop what the agent in the open pane is working on while keeping it and its session running, "clear the prompt" to empty its unsent prompt, and "scratch that" to delete only the words typed for the last thing you said. A clear can be undone when everything in the prompt was dictated. The three commands work with Claude Code, Codex, OpenCode and Pi; Devin is not supported. They work only in typing mode: said with typing mode off, they run nothing and the app asks you to say "typing on" first. See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice.md#interrupt-clear-and-scratch-that).
