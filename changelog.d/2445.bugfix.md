## OpenCode started from an undeclared wrapper reaches Idle

An OpenCode 2 agent started through a wrapper, such as a script, in a role or pane that does not set `agent = "opencode"`, never reached **Idle** once it had started a turn. Its card stayed on **Waiting** with `Background: 1 command` even when nothing was running, so a delegate or message waiting for the agent to go idle was held back.

Once such an agent reports in, the deck now recognises its OpenCode server the way it already did for a wrapper declared as OpenCode, and the card reaches **Idle** when the turn ends.
