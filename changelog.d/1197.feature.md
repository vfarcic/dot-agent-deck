## One navigation rail on every desktop screen

The desktop app's left rail is now the same on the agent overview as on the deck. Selecting the overview used to swap in a two-button rail, so **Settings** and the deck's panels vanished; now every entry stays, and the highlighted entry shows which screen you are on. The deck's **Runs** entry is now called **Deck**. Settings opens straight over the overview, and voice follows the rail: *"open settings"*, *"show everything"* and *"go back to the deck"* work from both the deck and the overview.
