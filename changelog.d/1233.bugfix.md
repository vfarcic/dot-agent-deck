## A prepared launch starts its roles in the project directory it verified

A launch from the desktop's New agent dialog or Runs screen checks that the project directory is still the one it prepared, and then starts each role there. If the directory was renamed away and a different one put under the same name in between, the role used to start in the replacement. On Linux the role now starts in the directory that was checked. On macOS the name is checked again just before the start, which narrows that window but does not close it. On both, a launch whose project directory is no longer a directory at start time is refused, instead of starting the role in your home directory.
