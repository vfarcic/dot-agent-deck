A Codex pane whose command sets its own `CODEX_HOME` or changes folder before starting Codex, such as `CODEX_HOME=/elsewhere codex`, `env CODEX_HOME=/elsewhere codex` or `cd project && codex`, no longer counts on the deck's hooks running there. Codex may then load a home or folder the deck did not set its hooks up for, so the pane's card in the TUI and its tile in the desktop app now show Thinking while Codex's screen changes and Idle once it is still, instead of staying Idle while Codex works. A launcher script that does the same inside itself is still invisible to the deck; [Codex events not showing](https://agent-deck.devopstoolkit.ai/docs/troubleshooting.md#codex-events-not-showing) says what to do about it.
