## The doorbell no longer types into a dialog, a draft or an agent it can't read

When an agent's own wake-up wasn't working, the deck typed its doorbell line into the agent's pane whenever the agent reported it was idle. The line could land in a dialog that had just opened, beside text you were typing, or in an agent whose screen the deck could not read, and an Enter could submit something other than the deck's line.

Now the deck types the doorbell only into a Claude Code version it has measured, and only while the agent's input box is on screen and empty. The line starts with six letters in brackets, drawn afresh each time, such as `(bmrtzx) dot-agent-deck: message m-… waiting, run: dot-agent-deck inbox fetch`. The deck checks that the line reached the input box intact before it presses Enter, and that the agent took it afterwards. If anything changes on the way, it presses no Enter; when it cannot be sure where its line went, it types nothing more into that agent until you submit or clear its input box, and the TUI card and the desktop tile say so. Keys you type while the deck is typing are sent after it, exactly as you typed them.

The deck does not type the doorbell into Codex, OpenCode, Pi or Devin, or into a Claude Code version it has not measured. Their native wake-up, where there is one, still delivers. When nothing does, the agent's messages wait, and its card and tile say `waiting for the agent to fetch it. Send it a prompt.`: type a prompt in the agent's pane and it takes them at that turn. `dot-agent-deck daemon status` shows `none` under WAKE for such an agent, and an orchestrator's notice that a task has not reached its worker says the same. Other new card reasons say when the agent did not take the deck's Enter, when the deck's line may still be in the input box, and when a dialog may have taken the deck's keys.

See [Orchestration → Which agents wake for messages](https://agent-deck.devopstoolkit.ai/docs/orchestration.md#which-agents-wake-for-messages) and [Troubleshooting → A card says `waiting for the agent to fetch it. Send it a prompt.`](https://agent-deck.devopstoolkit.ai/docs/troubleshooting.md#a-card-says-waiting-for-the-agent-to-fetch-it-send-it-a-prompt).
