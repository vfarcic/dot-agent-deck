## The Daemons screen is no longer experimental

The desktop app's **Daemons** screen is now in the rail for everyone, without the `experimental` flag. It shows the agents of the daemon chosen in the Dashboard's **Daemon** selector as live terminal tiles side by side, and the Dashboard's **Open daemons** button leads there too. The screen brings its **Command** menu (`Ctrl+K` / `⌘K`), its keyboard shortcut guide (`?`) and its stop button, which closes the selected agent or, with none selected, stops the daemon after asking. Saying "open daemons" by voice now opens it as well.

The Projects, Orchestrations and Agent Profiles screens stay behind the flag, and so do the Daemons screen's **Edit loop** and **Configure agents** buttons that lead to them. See [The Daemons screen](https://agent-deck.devopstoolkit.ai/docs/desktop/index.md).
