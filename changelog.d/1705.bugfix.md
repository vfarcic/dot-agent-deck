## Copying an Agent's Output Works When the Agent Handles the Mouse

In the desktop app, selecting text in Claude Code's pane put nothing on the clipboard: Claude Code handles the mouse itself, highlights what you drag across and asks the terminal to copy it, and the app ignored that request, so `⌘C` had nothing to copy either. The app now copies the text an agent asks it to, so releasing the mouse after a drag in such a pane puts the text on your clipboard. The TUI passes an agent's own copy on to your terminal in the same way, so it reaches your clipboard when your terminal lets programs set it. Neither client ever lets an agent read your clipboard.

On Windows, `Ctrl+C` in the desktop app now copies the highlighted text and clears the highlight, as it does in Windows Terminal. With nothing highlighted it still interrupts the agent, and on macOS and Linux plain `Ctrl+C` still always interrupts.
