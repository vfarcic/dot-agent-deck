## Choose the deck by voice once the New agent dialog is open

With the desktop's New agent dialog open, saying "deck build box", "use the local deck" or "switch to the build box deck" now chooses that deck, exactly as clicking it does: the chosen directory is cleared and the deck's own directories are listed, while a typed Name or Command is kept. Before this, a deck could be named only as the dialog opened ("new agent on the build box"), so a wrong or missing deck meant closing the dialog and starting over.

The request has to include the word "deck". That keeps a directory or agent name written to steer the voice model from switching the deck on its own, and "switch to the build box" without it is answered with the phrasing that works. A deck that cannot take a new agent is refused with the reason the dialog shows beside it. Saying "deck" or "the deck" by itself over the dialog now asks which deck, rather than leaving the overview for the deck screen.
