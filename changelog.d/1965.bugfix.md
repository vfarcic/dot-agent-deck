## Pi Agents Start Again

In v0.49.2 every Pi agent the deck started exited right away, and Pi started by hand printed `Failed to load extension ".../extensions/dot-agent-deck/index.ts": ... Cannot find module './usage-file.ts'`. The deck installed its Pi extension without one of the files the extension needs. It now installs every file, so Pi agents start, report their status and take part in orchestrations as before. Nothing needs to be done after upgrading: the deck rewrites the extension when its daemon starts and before each Pi agent starts.
