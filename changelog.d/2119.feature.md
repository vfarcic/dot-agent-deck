## Generate a project's config from the desktop app, by click or by voice

The desktop app can now ask an agent to write the project's `.dot-agent-deck.toml`, as the TUI's `g` does. Press **Generate config** on the agent's row on the Dashboard or in the header of its pane, or say "generate config with" and the agent's name ("generate config" alone in its pane). The same **Generate .dot-agent-deck.toml** dialog asks first, and nothing is sent until you press **Yes**. When the project already has a `.dot-agent-deck.toml`, the control reads **Update** in both clients (`[Update g]`, **Update config**, or say "update config"), and the agent reads the existing file and proposes changes to it, keeping what you wrote unless you agree to drop it.

After **Yes**, both clients bring the agent in front of you, the TUI by focusing its pane and the desktop app by opening it, and both say `Config request sent to the agent's inbox.` The agent then proposes a config in its pane and writes the file once you approve it. The request reaches the agent as a deck message, so any supported agent can take it. When it cannot be sent, both clients say why in the same words.

The dialog in both clients now offers only **Yes** and **No**. The **Never** choice and the `auto_config_prompt` hint are gone, because the dialog opens only when you ask for it. `auto_config_prompt` is still accepted in `config.toml` but has no effect.

Generate config needs a daemon from this release. Against an older daemon, both clients say `This daemon is too old to generate a config. Upgrade the daemon to use Generate config.` and send nothing. Restart the daemon on the new release to use it. See [Quick setup](https://agent-deck.devopstoolkit.ai/docs/orchestration.md#quick-setup).
