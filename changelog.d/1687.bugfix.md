## Worktree reclaim no longer mistakes a fork's pull request for yours

`dot-agent-deck worktree list` and `worktree reclaim` decide whether a worktree's branch is merged from its pull request. A merged pull request from someone else's fork, opened from a branch that happened to share your branch's name, could make your worktree read as merged and be removed. Pull requests from forks are now ignored, so only a pull request from your own repository's branch counts.
