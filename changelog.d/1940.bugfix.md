## Fewer Duplicate Deck Messages After an OpenCode or Pi Pause

When OpenCode or Pi stopped responding to the deck for a while after the deck handed it a message, and before it started on that message, the deck could send the message again, marked as a possible repeat, so the agent received it twice. With the OpenCode plugin and Pi extension from this release, the deck holds that automatic repeat back while the agent still has the first copy. If the first copy is lost later, for example when you abort the turn, the deck may send the message again, marked as a possible repeat, or, once it has made as many attempts as it allows, show that it cannot tell whether the message was delivered. An OpenCode or Pi agent that was already running before you upgraded keeps the integration it started with and can still get a message twice after a long pause; restart the agent to pick up this release's.
