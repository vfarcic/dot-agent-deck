## OpenCode and Pi No Longer Get a Deck Message Twice After a Pause

When OpenCode or Pi stopped responding to the deck for a while after the deck handed it a message, and before it started on that message, the deck could send the message again, marked as a possible repeat, so the agent received it twice. The deck now holds the repeat back while the agent still has the first copy, and sends it once that copy is lost, for example when you abort the turn. An OpenCode plugin or Pi extension from an earlier release can still get the message twice after a long enough pause, because it does not tell the deck what it holds at the moment it hands a message to the agent; the plugin and extension from this release do.
