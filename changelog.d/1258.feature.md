## See how much room a deck's machine has left

Before you start more agents on a deck, you can check the machine it runs on: free and total disk space where the deck works, where sibling worktrees are created and where test scratch files go, plus load per core with the core count, memory used and available, and how old the figures are. For a remote deck these are the remote machine's figures.

In the TUI, press `m` in command mode to open the **Host of this deck** overlay, and `Esc` to close it. The key can be remapped as `host_metrics` under `[dashboard]` in `keybindings.toml`. In the desktop app, each daemon's section on the Dashboard shows the same figures in a **Host of this deck** panel, so with several daemons shown you see every machine at once. A figure the machine cannot report reads `unknown` rather than `0`; memory is `unknown` for a deck on macOS. A daemon from an earlier release, or one running on Windows, says **Host metrics are not available from this deck**.

See [Check the machine a deck runs on](https://agent-deck.devopstoolkit.ai/docs/session-management.md#check-the-machine-a-deck-runs-on).
