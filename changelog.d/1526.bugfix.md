## The orchestrator no longer misses a worker that is waiting for input

When you delegated to a worker that was already stopped at a prompt, or one that stopped at a prompt before its task arrived, the deck's report that the worker was waiting for input could be dropped if the task reached the worker while the report was still waiting to be written, for example behind an unsent draft in the orchestrator's pane or on a busy machine. The orchestrator then never heard that the worker needed attention. The report now arrives once the orchestrator's pane is free, whenever the task reached the worker.
