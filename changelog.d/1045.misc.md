## The TUI and the desktop app now use the same words

The terminal TUI and the desktop app used different words for the same things. A running agent was a "session" or a "pane" in the TUI and an agent in the desktop. An orchestration was a "workflow" or a "live loop" in the desktop. The desktop also called the daemon a "Deck". Both clients now use one set of words, taken from the TUI wherever the TUI had one: **orchestration**, **daemon**, **agent**, **dashboard**, **orchestrator**, **delegation**, **event**, **Needs Input** and **Schedules**, with **Close**, **Create** and **Activate** as the verbs. The controls do what they did before; what changed is what they are called.

**In the TUI.** Anything that means one agent now says so: "No active agents", the dashboard's "{n} agent(s)" title, "Filter agents", "Rename agent", "Close selected agent", and the **New Agent** button and form, which used to be **New Pane**. The stats bar's "waiting" count now reads "needs input", which matches the status on the card. The **Scheduled Tasks** manager is now **Schedules**, and `dot-agent-deck schedule`'s output and help and the config validation messages say "schedule" too ("No schedules."). The `[scheduled_tasks]` config key is unchanged, so existing config files keep working. The help overlay says "Return to command mode" instead of "Normal mode". Pane and card are still the words for an agent's terminal view and its tile on the dashboard.

**In the desktop app.** The "Deck" wording from earlier releases is back to **daemon**. That covers the **Daemon** selector, the **Daemons** section in Settings, **All daemons**, **Local daemon** / **Remote daemon**, and **Start daemon**, **Stop daemon** and **Replace daemon**. The Overview is now the **Dashboard**. Workflows and live loops are **orchestrations**, and you bring one up with **Activate orchestration**. The COORDINATOR badge reads **ORCHESTRATOR**, and "Message coordinator…" is now "Message orchestrator…". Handoffs are **delegations**, with the edge status "delegated" instead of "dispatched". The evidence drawer is now **Events**. **Create agent** replaces "Start agent". An agent's dashboard row has **Close {name} agent**, which stops that agent. The full-window agent view's own dismiss button, which only leaves the view, is now **Back to dashboard**. With the experimental flag on, the rail's **Deck** and **Workflows** entries read **Daemons** and **Orchestrations**. By voice, the older words ("open deck", "go back to the deck", "start orchestration") still work, the New agent dialog's daemon is chosen with "daemon build box" (and "deck build box" still works), and stopping one agent is still said "stop {name}": "close" by voice only ever closes a view.

**Your saved orchestration role order is kept.** The desktop stores that order under a new name. The first time it looks for the order after the upgrade and finds none under the new name, it copies the one saved under the old name across and removes the old entry, so an order you arranged before upgrading is still there. A saved order that cannot be read is dropped and the default order used, instead of breaking the orchestration editor.
