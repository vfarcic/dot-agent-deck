## Codex installed with npm under Node.js 23.11 or later gets its input box checked again

Codex 0.169.0 installed with `npm install -g @openai/codex` and run under Node.js 23.11 or later (Node 24, for example) never had its input box checked on Linux: once you typed into its box, its card said `the deck can't check this agent's input box. Check its pane.` until Codex restarted, and its messages waited for a prompt. The deck now checks that Codex's box as it checks any other Codex's. A Codex installed with pnpm or bun, or into a project's own `node_modules`, usually still isn't checked under those Node.js versions; reinstall it with `npm install -g @openai/codex` to have its box checked.
