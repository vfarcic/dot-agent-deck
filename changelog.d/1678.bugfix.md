## OpenCode Cards No Longer Turn Idle When a Subagent Finishes Mid-Turn

While OpenCode ran a subagent, its card could read **Idle** as the subagent started and again as it finished, even though the main agent was still working, and the card's last prompt showed the instructions the subagent was given instead of yours. A subagent's work no longer changes the card's status or prompt: the card follows the main agent, and a subagent still running after the main agent answers is shown on the `Background:` line.

An OpenCode subagent's permission prompt still shows **Needs Input**, and is now told apart from the main agent's. Answering it returns the card to **Idle** if the main agent had already answered, with the subagent still on the `Background:` line while it keeps running; before, answering it turned the card **Thinking** and hid that line. A subagent that ends without its prompt being answered takes its prompt and its `Background:` entry with it, and the card goes back to where the main agent is: **Idle** if its turn had ended, **Thinking** if not. The card stays on **Needs Input** while another prompt is still waiting for an answer.
