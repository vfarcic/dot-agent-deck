## No more "Failed to open editor" from Codex when its home is in a folder you let it write

When Codex's home (`~/.codex`, or `CODEX_HOME`) was inside a folder you let Codex write, with `sandbox_workspace_write.writable_roots` or `--add-dir`, the deck couldn't check Codex's input box, but it tried anyway. Each time, Codex showed `Failed to open editor: editor exited with status exit status: 1`, and the card kept saying there might be an unsent draft.

The deck now sees that setup before it checks anything, as it already did for a home inside the project folder or under `/tmp`. It types nothing into that Codex's box, and once anything has been typed there, its card in the TUI and its tile in the desktop app say `the deck can't check this agent's input box. Check its pane.` until Codex restarts. A prompt you send hands the agent its messages. To have the box checked, move `CODEX_HOME` out of the folders you let Codex write.
