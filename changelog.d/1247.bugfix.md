## The desktop's New agent dialog keeps what you typed when it closes

Closing the desktop app's New agent dialog no longer throws the form away. Esc, a click outside the dialog, its close button, the directory browser's `q` and a spoken "close" (or "cancel", "never mind") now keep the chosen deck and directory, the Mode, the Name and a hand-edited Command, and opening New agent again puts them back with a note saying so. The form is replayed against the deck as it is now rather than copied: the deck is chosen again only if it can still take an agent, the directory only if the deck still lists it, and the Mode only if it is still offered, and the note says which of them could not be restored. An untouched Command is filled from the deck's current default, and a run name for an orchestration is worked out again against the runs live now.

A new **Discard** button, or saying "discard" on its own, closes the dialog and forgets the form. A start the deck accepted also forgets it. Opening the dialog from one deck's own New agent button, or with "new agent on the build box", uses that deck and keeps only a typed Name and Command from the saved form. The saved form lasts while the agent overview is open; switching to the deck screen loses it.
