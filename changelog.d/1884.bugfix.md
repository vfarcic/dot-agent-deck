## Fewer Agent Panes Fail to Open on macOS With "Device not configured"

On macOS, opening the terminal for a new agent pane could fail now and then with `failed to openpty: … Device not configured`, and the pane did not start. When macOS reports that error, the deck now tries to open the terminal up to three times, a few milliseconds apart, before giving up, so a pane that hits it can still start. If all three tries fail, or the terminal fails to open for any other reason, you see the same error as before.
