## A Failed Terminal Open on macOS Is Retried Before the Agent Pane Fails

On macOS, opening the terminal for a new agent pane could fail with `failed to openpty: … Device not configured`, and the pane did not start. When macOS reports that error, the deck now tries to open the terminal up to three times, a few milliseconds apart, before showing it. If all three tries fail, or the terminal fails to open for any other reason, you see the same error as before.
