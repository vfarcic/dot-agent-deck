## Codex telemetry no longer switches off when its arguments mention `otel.`

With telemetry on, a Codex agent whose prompt, model name or path happened to contain `otel.` (for example a prompt asking it to fix `otel.rs`) sent no traces or metrics for that run. The deck now leaves Codex's export to you only when its arguments set something under `otel` with `-c` or `--config`, as [Telemetry](https://agent-deck.devopstoolkit.ai/docs/telemetry.md) describes.
