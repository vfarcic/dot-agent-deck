## The landing page no longer tells macOS users the desktop app is unsigned

The desktop section of [agent-deck.devopstoolkit.ai](https://agent-deck.devopstoolkit.ai) still read "Unsigned, so macOS will stop you" and sent readers to the release notes for the route past a security dialog. That stopped being true at v0.42.0, whose `.dmg` is signed with the project's Apple Developer ID and notarized by Apple, so macOS should ask only to confirm opening an app downloaded from the internet.

The caveat now says what v0.42.0 actually carries: a signed, notarized `.dmg` and an unsigned `.deb`, which `dpkg -i` installs without checking any package signature, so on Linux the provenance command is the only check anybody makes. It tells you to run that `gh attestation verify` command first on either platform, and to read the notes of the release you download, which say whether that release's macOS build is signed. If a signed build is reported as damaged or from an unidentified developer, it says not to override that and to report it. The desktop app is still labelled alpha, and there is still no Windows bundle.
