## `config get` says when `config.toml` is a link to something that is gone

When `config.toml`, or a folder it is in such as `~/.config/dot-agent-deck`, is a link to a file or folder that is no longer there (moved, or on a drive that isn't mounted), `dot-agent-deck config get` used to print the default value without a word, while the deck held the doorbell off for Claude Code and Codex because it could not read the file. `config get`, `config set` and the TUI now print `Failed to read config at <path>: …` naming the missing link, so the value `config get` shows is no longer mistaken for the setting in use. `config get` still prints the default value after that line and exits `0`. Put the file or folder back, or point the link at it.

See [Configuration](https://agent-deck.devopstoolkit.ai/docs/configuration.md).
