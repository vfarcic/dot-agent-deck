## Generated orchestrations start with rules for working safely as a team

When the deck generates a `.dot-agent-deck.toml` for a project, the worker roles it suggests now come with the working rules that teams otherwise added after something went wrong. A worker reports back to the orchestrator instead of stopping to ask you something or handing work to another role, and opens that report with its outcome: done, blocked, or needs a decision. Every role except `researcher` checks it is on the branch or commit its task names and stops rather than switching if it is not. Roles that change files leave other agents' changes alone and stage only the files they changed, so another agent's work in the same checkout does not end up in their commit.

Configs you already have are not changed; to pick up the new wording, regenerate the config or copy it from the role library into your own `prompt_template`s.

See [Role library](https://agent-deck.devopstoolkit.ai/docs/orchestration.md#role-library).
