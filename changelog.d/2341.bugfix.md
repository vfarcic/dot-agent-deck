## A deck message Claude Code never took is no longer marked delivered

When the deck handed a message to Claude Code through its prompt, it counted the message delivered as soon as its own hook had written it. If another `UserPromptSubmit` hook of yours then blocked that prompt, for example a policy or secret-scanning hook, Claude never saw the message, yet the deck showed it acknowledged and never sent it again.

The deck now counts such a message delivered only once Claude's session transcript shows that Claude took the prompt that carried it. A message whose prompt was blocked stays undelivered and is handed over again, marked as a possible repeat. If its repeats are used up too, it shows as uncertain, with Retry and Cancel, instead of as delivered. The repeat can wait until Claude's next turn ends. Nothing needs to be configured.
