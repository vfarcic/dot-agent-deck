A Codex agent started through a launcher, such as a role whose command is `devbox run codex-big` with `agent = "codex"`, gets its messages again after something is typed into its input box. The deck now checks that Codex's input box when the launcher puts its own `node` first on `PATH` or passes Codex `-c` options that don't change its key bindings, so the doorbell rings once the box is empty instead of every message waiting with `waiting for the agent to fetch it. Send it a prompt.` until the agent restarts.
