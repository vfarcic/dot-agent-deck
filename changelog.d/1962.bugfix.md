## The Local daemon section leads with the app's upgrade whenever the app can upgrade itself

**Upgrade** on the Dashboard's **Local daemon** section now opens the app's own upgrade first whenever the app can upgrade itself, or was upgraded and waits for a relaunch, not only when the `dot-agent-deck` CLI is behind too. Before, with the CLI current and the daemon on this machine older than the app, the button restarted the daemon onto the app's build without offering the app first, so a TUI started from a newer CLI then offered to restart the daemon onto its own, and the old app ended up talking to a newer daemon.

The button is now named for everything it covers, for example `Upgrade Agent Deck and the daemon on this machine`, and hovering it shows the app's line beside the others. When only the app is behind, the section offers `Upgrade Agent Deck on this machine`. An app that cannot upgrade itself, such as one in a folder you cannot write, is still left to the banner's dialog.

See [Upgrade the CLI and the daemon on this machine](https://agent-deck.devopstoolkit.ai/docs/desktop/daemons.md#upgrade-the-cli-and-the-daemon-on-this-machine).
