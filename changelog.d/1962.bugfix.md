The Dashboard's **Local daemon** upgrade now leads with the desktop app's own upgrade whenever the app can upgrade itself or is waiting for a relaunch, even when the CLI is current or not installed and only the daemon is behind. This prevents the old app from restarting the daemon onto a release that a newer CLI would immediately replace again. The upgrade button's accessible name and hover text now name the app alongside the CLI and daemon. See [Upgrade the CLI and the daemon on this machine](https://agent-deck.devopstoolkit.ai/docs/desktop/daemons.md#upgrade-the-cli-and-the-daemon-on-this-machine).
