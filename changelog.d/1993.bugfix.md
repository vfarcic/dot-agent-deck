## An agent's card shows the last prompt you typed, not one the agent added itself

When a Claude Code agent's background command or subagent finished, the agent's card showed Claude Code's `<task-notification>` text as its last prompt: in the desktop app's Last prompt column and on the TUI card. OpenCode had the same problem with turns it adds on its own, such as a background task's result or the turn that continues after a compaction. The card now keeps showing the prompt you typed before, and a slash command you type still shows as your prompt.
