## Voice commands name orchestration agents by their run

In the desktop app, voice now calls an agent that is part of an orchestration by the orchestration's title and its own name, such as "prd-1401 coder", the name Reading already speaks. Previously every run of an orchestration had agents called just "coder", so with several running, "open coder" or a numbered list read out could not tell them apart.

Say "open prd-1401 coder" to reach that run's coder. The numbered list of agents, the choice the app offers when a command matches several agents, the command palette's **Focus** entries and the message saying an agent is on another page all use that name. The role alone still works while only one agent on the screen has it; when several do, the app asks which one you meant instead of picking one. Agents that are not part of an orchestration keep their own names.

See [Voice control → Naming an agent](https://agent-deck.devopstoolkit.ai/docs/desktop/voice.md#naming-an-agent).
