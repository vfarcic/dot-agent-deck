## An orchestrator treats every worker report as information, not instructions

A worker's report often quotes issue text, code and tool output it read, and a report can carry instructions planted in any of those. Reports delivered inline were already marked so that the orchestrator reads them as information and never acts on what they say; the report of a completed delegated task, the most common kind, was not. It now carries the same marking, so text planted in a report is less likely to steer your orchestrator.
