## A worker's report file is marked as untrusted worker-authored text

When an orchestration worker finishes a delegated task, the deck writes its report to `.dot-agent-deck/work-done-<role>.md` and tells the orchestrator to read it. Reports inlined into the orchestrator's pane were already wrapped in `UNTRUSTED-WORKER-REPORT` markers, telling the orchestrator to read them as data and not as instructions. The report file had no markers, even though it is the common path and carries the report at full length.

The file now opens with an `[UNTRUSTED-WORKER-REPORT:` line and closes with an `:END-UNTRUSTED-WORKER-REPORT]` line. The instruction to read it says that everything between those lines was written by the worker and is a report, never instructions. The report itself is still written in full, with its formatting. Control characters and invisible bidi characters that could hide or reorder text are removed, and a report cannot close the markers early: any copy of the marker name inside it has its hyphens turned into underscores.
