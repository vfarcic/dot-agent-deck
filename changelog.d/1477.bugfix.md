## More Keys Reach the Agent the Same Way from the TUI and the Desktop App

The TUI now sends the same keys to an agent as the desktop app does in two more cases. A program in a pane that asks for the alternate form of the arrow keys, Home and End (as some editors and pagers do) now gets that form, and the ordinary form again when it switches back. Home and End with Ctrl, Shift or Alt held, Shift+Delete, Ctrl+Shift+Backspace and Ctrl+Alt+Backspace now reach the agent with their modifiers, so they do whatever the agent does with them, as in the desktop app: for example Shift+Home selects to the start of the line in OpenCode. Where an agent has no use for one of them (Codex and Devin ignore Home and End with a modifier), the key no longer acts as a plain Home or End; use Home, End or the other line-editing shortcuts instead.
