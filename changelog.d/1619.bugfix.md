## Remote upgrade restarts with many live agents

Choosing **Restart now** during `dot-agent-deck remote upgrade` (or the desktop app's upgrade) no longer fails when the remote daemon runs a very large number of agents. The list of work to stop used to travel on the ssh command line, and a long enough list made the command too long to start, so the restart failed and the old daemon kept running. The list is now sent to the remote separately, however long it is.

If the build installed on the remote is older than this release and the list is too long for it, the upgrade stops before asking the daemon anything and says so; the daemon and its agents keep running. Restart the daemon on that machine with `dot-agent-deck daemon restart`.
