## Remote upgrade restarts with many live agents

Choosing **Restart now** during `dot-agent-deck remote upgrade` (or the desktop app's upgrade) now works when the remote daemon runs many more agents than before. Past a few hundred agents the restart used to fail and leave the old daemon running.

If the build installed on the remote is older than this release, or the list of work to stop is still too large, the upgrade stops before asking the daemon anything and says so. The daemon and its agents keep running. Restart the daemon on that machine with `dot-agent-deck daemon restart`.
