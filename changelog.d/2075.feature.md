## Agent questions stay answerable, and remind you once

A question an agent asks (a permission prompt, a menu or a form) now stays answerable from the deck for as long as it waits: in the agent's pane, from the desktop app or by voice. Before, the deck stopped offering an answer after an hour and left the question to the agent's own pane. For Claude Code that wait is now about 24 days, the longest Claude Code keeps the deck's hook running; for Codex, OpenCode and Pi the deck sets no limit. After upgrading, restart the daemon or run `dot-agent-deck hooks install` so Claude Code's hook gets the longer wait.

While a question waits, the TUI card and the desktop tile show `QUESTION` and how long it has waited, for example `QUESTION 12m`. Once it has waited 10 minutes, the deck sends one notification for it, naming the agent and the question, and never repeats it; a question answered sooner sends none. The TUI sends it to the terminal as an OSC 9 notification, which terminals such as iTerm2, WezTerm and Ghostty show; the desktop app posts a system notification.

Change the wait with `dot-agent-deck config set notifications.question_after_minutes <minutes>` in the TUI, or under **Settings → Notifications** in the desktop app; `0` (or **Off**) turns the notification off. See [When a question waits](https://agent-deck.devopstoolkit.ai/docs/session-management.md#when-a-question-waits).
