## Voice: "switch daemon to …" hears the daemon you named

In the desktop app, saying "switch daemon to" or "switch deck to" followed by a daemon's name switches to that daemon, or says no daemon matches the name when none does. Occasionally it answered "I could not tell which daemon you meant" although a daemon was named.

See [Voice](https://agent-deck.devopstoolkit.ai/docs/desktop/voice.md).
