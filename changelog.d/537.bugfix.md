## A refused hook install no longer overwrites your own `.bak` file

When an agent's config file (for example `~/.claude/settings.json`) did not parse, `dot-agent-deck hooks install` and `hooks uninstall` copied it to `<name>.bak` beside it, replacing any file already there, including a copy you made yourself before editing. An existing `<name>.bak` is now left alone, and the message says `original not copied: <name>.bak already exists and was left as it was`. Your config file itself is still left unchanged, and the command still exits with a non-zero status. See [Troubleshooting](https://agent-deck.devopstoolkit.ai/docs/troubleshooting).
