## Run the daemon as a service

`dot-agent-deck daemon install` keeps the daemon running when nobody has the deck open. It sets the daemon up as a systemd user service on Linux, or a LaunchAgent on macOS, and starts it. From then on the daemon starts at login, or at boot on Linux once lingering is on (`sudo loginctl enable-linger "$USER"`, which the command suggests when it is off). It also starts again after a crash and after `remote upgrade`. Schedules fire after a reboot without anyone opening the deck, and a remote host or the desktop app finds a daemon already running.

The command fills in the deck's own path and turns the idle shutdown off. It carries the socket settings of the shell you run it from, and reports success only once the daemon answers there. It never stops a running daemon: with one already running, it sets the service up for the next login and says how to switch. `daemon stop` and the TUI's **Stop** still stop the daemon, and it stays stopped until the service starts it again. `dot-agent-deck daemon uninstall` removes the service and leaves a running daemon running. The macOS LaunchAgent has not been tested on a Mac yet.

See [Run the Daemon as a Service](https://agent-deck.devopstoolkit.ai/docs/daemon-service.md).
