## Worker Reports Saved at `work-done-<role>.md` Are No Longer Overwritten

A worker that saved its own report to `.dot-agent-deck/work-done-<role>.md` lost it when it then ran `dot-agent-deck work-done`. The deck wrote its copy of the completion over that file, and nothing reported the loss. This happened whether the worker signalled with a short `--task` summary or passed that same file to `--task-file`.

The deck now leaves such a file as it is and saves the report to a new file in the same `.dot-agent-deck` directory. The orchestrator is told where the report is, and that the existing file was left alone because it may hold more of the worker's report. Reports the deck wrote itself are still replaced as before.

See [Orchestration](https://agent-deck.devopstoolkit.ai/docs/orchestration#the-report-went-to-a-different-file-than-work-done-rolemd) for details.
