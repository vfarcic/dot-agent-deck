Building from source on an older Rust toolchain now fails with cargo naming the version it needs, instead of an arbitrary compile error partway through. `Cargo.toml` declares `rust-version = "1.97.1"` — the toolchain this project is built and tested on — and a test keeps that number in step with the pins in `devbox.json` and the CI workflows. An older rustc may still work; nothing here tests one, so nothing promises it.
