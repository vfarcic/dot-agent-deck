## Declared minimum supported Rust toolchain

Building from source now fails fast and clearly on a toolchain that is too old. The workspace declares `rust-version = "1.93.1"`, so cargo stops with `rustc 1.93.0 is not supported by the following packages: dot-agent-deck@0.1.0 requires rustc 1.93.1` instead of letting the build die somewhere inside a dependency with an error that looks unrelated to the toolchain. This only affects people who compile the project themselves — most visibly Nix users who take the overlay, or who set `inputs.dot-agent-deck.inputs.nixpkgs.follows`, since both build against their own nixpkgs' rustc rather than the one this flake pins.

The installation docs previously told those users their nixpkgs had to carry "rustc 1.85 or newer", which was the *edition-2024* floor rather than a tested one: nothing declared or enforced any minimum, and the project is only ever built on the toolchain pinned in `devbox.json` and CI. 1.93.1 is measured — the oldest toolchain the whole workspace was verified to compile on, tests included — and it is deliberately lower than the pinned toolchain, so a nixpkgs a few releases behind current stable still works. [Installation](https://agent-deck.devopstoolkit.ai/docs/installation) has the updated numbers.
