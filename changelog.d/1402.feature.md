The desktop agent screen now has a stop-icon **Close agent** control. It uses the same confirmation and close request as the dashboard row, then returns to the dashboard when the daemon has ended the agent; closing an orchestration role leaves the other roles running. With typing mode off, saying “stop”, “stop it”, “stop that” or “close this agent” on that screen opens the same confirmation without stopping anything until you confirm. In typing mode, “stop” still interrupts only the agent's current turn.
