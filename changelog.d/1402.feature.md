The desktop app's agent pane has a **Close <name>** control beside its back button, so the agent it shows can be stopped from the pane: it opens the same confirmation the dashboard row's stop control opens — naming the daemon the stop request goes to, and saying when only one role of an orchestration closes — and once the daemon stops listing the agent, the pane closes with it and you are back on the screen you opened it from. By voice, a bare "stop", "stop it", "stop that" or "close this agent" on the pane asks the same thing, behind the same confirmation you answer by hand; while typing mode is on, a bare "stop" still just interrupts the agent's turn, and ending an agent stays out of reach until you leave typing mode.
