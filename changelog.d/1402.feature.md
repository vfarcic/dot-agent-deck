## Close an agent from its desktop pane

The desktop agent pane has a red **Close agent** stop-icon button, separate from **Back to dashboard**. It asks for confirmation, stops that agent and returns to the Dashboard. Closing an orchestration role warns that the other roles keep running; use the orchestration's **Close** on the Dashboard to end the whole run.

With typing mode off, say **“stop”**, **“stop it”**, **“stop that”** or **“close this agent”** on its own to open the same confirmation. With typing mode on, “stop” still interrupts the agent's turn without ending its session.
