## Installing without a package manager is now a first-class option

Downloading a binary is how most people install a single-binary tool, and the docs treated it as an afterthought. On the [Installation](https://agent-deck.devopstoolkit.ai/docs/installation) page, **Download Binary** sat below a ~100-line Nix section with its own nested subsections, so it was effectively invisible; it has moved up beside Homebrew. A new **Choose an install method** table sits at the top with all four options — Homebrew, a downloaded binary, Nix, building from source — and what each one suits, so you can jump straight to the one you want.

The section itself was a single sentence pointing at the Releases page, which left you holding a file. It now names the four published assets (`dot-agent-deck-linux-amd64`, `-linux-arm64`, `-darwin-amd64`, `-darwin-arm64`), shows the `chmod` and the move onto `PATH`, and covers the two things that actually bite: `~/.local/bin` not being on `PATH` on every distribution, and macOS refusing a binary it considers downloaded from the internet.

**Getting Started's Linux instructions no longer assume Homebrew.** They read `# 1. Install via Homebrew (if available)` — an "if available" that quietly conceded Homebrew is uncommon on Linux, while the binary download was a footnote below the fold. Linux now leads with a `curl` of the published binary, which requires nothing to be installed first, and names Homebrew and Nix as alternatives for people who already use them. macOS still leads with Homebrew, which genuinely is the common path there, and now names the two Darwin assets for people who would rather not.
