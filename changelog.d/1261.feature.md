## Choose by number when a voice command matches several things

When something you say in the desktop app matches more than one thing on screen, such as "open the agent" with several agents on the dashboard, the app no longer just says so and waits for you to repeat yourself. A dialog opens in the middle of the screen, above whatever is open, asking which one you meant: it lists the matches as a numbered list with a **Cancel** button and a 20-second countdown, and the command you gave runs with the one you pick.

Pick by saying the number ("two", "number two", "the second one", "the last one"), by saying the name of one of the listed entries, by pressing its number key, or by clicking it. Say "cancel" or "never mind", press **Cancel**, or press Escape to choose nothing; Escape closes only the choice, not an agent's pane or the New agent dialog behind it, and the keyboard goes back to where it was. The list also closes on its own after 20 seconds. If an entry's name is itself a number or "cancel", saying just that name chooses nothing; say its number instead, such as "number two" for the second entry, or click it. Saying something else closes the list and treats what you said as a new command. A number, a listed name or a cancel is decided on this machine and is not sent to the Commands service. Nothing runs if the screen, the New agent dialog or the entry you picked changed after the list appeared, and a stop or an orchestration close chosen from the list still asks for confirmation. A refusal such as "switch to build, not staging" is never turned into a list. See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice#when-a-command-matches-several-things).

The New agent dialog now lists only the daemons that can take a new agent, so a daemon that is not connected or is a different version from the app no longer fills the dialog with its explanation; the dashboard still shows it with the reason and what to do. If no daemon can take one, the dialog says so in one line. Asking by voice for a daemon that cannot take a new agent gets a one-line answer naming it and why, such as "“build box” can't take a new agent: it is older than this app." See [New agent](https://agent-deck.devopstoolkit.ai/docs/desktop/new-agent).

While voice is on, the agents on the dashboard and the Daemons screen, and the daemons, directories and modes in the New agent dialog, show a number before each item, and saying the number ("three", "number three", "the third one") or pressing its number key chooses that item. See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice#choosing-by-number).

In the New agent dialog, say "filter" followed by some text, such as "filter docs" or "show only those starting with letter D", to narrow the directory list to names containing it, and "clear filter" to show them all again. See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice#filtering-directories).

While voice is on, a list too long for the window is shown a page at a time instead of scrolling, so everything you can choose by voice is on screen: the directories and modes in the New agent dialog fill it in columns, the dashboard and the Daemons screen show what fits, and "Page 1 of 3" shows beside the list. Say "next page" or "previous page" to turn it; numbers start at 1 on each page, numbers above nine can be said in words ("twelve", "number twenty-three"), and naming something on another page tells you which page it is on. The New agent dialog always shows every daemon that can take a new agent, and the Daemon selector's menu is numbered too. See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice#long-lists-are-shown-in-pages).
