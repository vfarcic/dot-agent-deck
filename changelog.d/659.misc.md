## Automated code review now covers every pull request instead of running dry mid-month

The repository's review bot was configured to re-review a pull request on every push, which consumed its monthly allowance about three times faster than the number of pull requests alone — enough that it exhausted the month partway through August and then reviewed nothing at all, silently and with no indication anywhere of why. It now reviews each pull request once, when opened, which fits comfortably inside the allowance and means no pull request goes unreviewed. The trade is that a review is not repeated after follow-up pushes; a human approval is already dismissed on every push, so those changes are still looked at.
