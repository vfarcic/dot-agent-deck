The desktop's **Incompatible daemon** note no longer says "Only the build stamps differ" when it is refusing a daemon across a declared compatibility break. Since a build-stamp difference stopped refusing anything, **Connect anyway** is offered only across a declared contract break, so the note beside it and the confirmation dialog now say that: the wire protocol agreed and you can still connect, but a declared break separates the two builds and some of what the daemon reports can be read with the wrong meaning. The usual way to hit this is upgrading the app while an older daemon keeps running with live agents.
