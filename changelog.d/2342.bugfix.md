## Deck messages reach a Claude Code conversation moved to the background

When you press Left in Claude Code's empty input box, Claude Code moves the conversation to a background session, and Escape or Enter brings you back to it. Until now, a deck message sent after that, such as a delegated task or a worker's report, never reached the conversation, and Claude did nothing with it. The deck now delivers it to the background session, and Claude acts on it there as it would in the foreground. Nothing needs to be configured, and this works with the hooks the deck already installed.
