## Voice: "how many agents are running" opens the counters, and "reset" clears the dashboard's filter

In the desktop app, asking "how many agents are running" on the agent dashboard usually just opened the dashboard you were already on, so nothing visible happened. It now opens the dashboard's counters, which show how many agents are working, waiting, idle or in error. Asking "which agents are running" still opens the agent dashboard. Saying "reset" on its own on the dashboard was sometimes refused with "nothing in that asks to clear the agent dashboard's filter". It now clears the filter much more reliably. If it is still refused, say "show everything".
