## Voice: "tell it …" on an agent's pane is read as typing to that agent more often

In the desktop app, with an agent's pane open, a sentence like "tell it the build has finished" or "tell it to go ahead with the refactor" means "type this into the agent's prompt". Since agent cards arrived, such sentences were often read as a reply to an agent's card instead, which only works from the agent dashboard, so the app answered that nothing was done. They are now read as typing to the open agent much more often. If one is still refused, start it with "type", for example "type the build has finished". Replying to an agent from its card on the dashboard ("reply to the coder yes go ahead") works as before.
