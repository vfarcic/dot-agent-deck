## A restored pane keeps its name when the daemon is slow to start it

When the deck restored your saved panes on start-up and the daemon took more than five seconds to start one, which can happen on a busy machine the first time a daemon starts Claude Code, the TUI gave up on that pane. The daemon still started the agent, so it showed up anyway, but its card was titled with its command instead of the name you saved, and the pane wasn't focused.

The TUI now waits up to fifteen seconds for a start, as the desktop app already did, so a slow restore comes back named and focused like any other. If a start takes longer than that, the agent still reaches the dashboard under its saved name. When the TUI gives up on a start, its message now says the agent may still appear, so check the dashboard before starting it again.
