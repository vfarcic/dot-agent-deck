## A Delegated Task That Arrived Too Early Is No Longer Left For You To Press Enter On

A `clear = true` delegate respawns its worker and then waits up to 30 seconds for that worker to announce itself before writing the task pointer. When the worker was slower than the wait — a cold Claude Code on a loaded machine — the deck wrote the pointer anyway, and the pointer parked unsubmitted at the worker's own input: `❯ Read .dot-agent-deck/worker-task-auditor.md for your task.`, sitting there until a human pressed Enter. Meanwhile the worker's own `SessionStart` arrived 7 to 11 seconds later, which was the deck being told, in so many words, that it had written too early — and it threw that away. The orchestrator was handed a "delegated worker went quiet" report for a worker that had received its task perfectly well.

The deck now acts on that late signal. A genuine `SessionStart` that turns up after the readiness wait has given up is treated as what it is — the readiness announcement, arriving late — and the deck submits the pointer the worker is already holding. The delegation completes on its own, with no keypress and no re-delegation. Nothing is retyped into the pane: the recovery is a submit only, so a worker whose input box already holds the task gets that task submitted rather than a second copy appended to it.

It is scoped to the case that needs it and stays out of every other. Only the respawn path that actually fell through its readiness wait can earn a recovery, only for an agent whose `SessionStart` genuinely precedes its first prompt (Claude Code today — Codex and OpenCode announce a session only once a prompt has been accepted, so for them a late start says nothing), and only once. A pane you have typed into since the deck's last write is refused before a byte, so pressing Enter yourself does not race the deck into submitting your unsent draft — that check is read under the same writer lock that stamps the clock it reads. A worker whose pointer was lost outright rather than parked still ends at the silent-worker report, exactly as before.
