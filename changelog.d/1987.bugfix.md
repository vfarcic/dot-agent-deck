## No stray "that agent is gone" message when you press Enter as the deck restarts

If you pressed Enter in an agent's pane at the moment the deck restarted, the status line could show "that agent is gone (the deck restarted)" for that pane, on top of the deck's restart notice. Now the restart notice is the only message: it names the agents the restart stopped, as it already did when you were not typing.
