## Claude Code agents stay Waiting while their background work runs

A Claude Code agent that started several background commands no longer drops to **Idle** while one of them is still running. When one of the others finished, Claude Code started a turn of its own to tell the agent, and the card counted that turn as a new one, so the command still running read as left over from an earlier turn. Turns Claude Code starts by itself to report a finished background command or subagent are no longer counted that way: the card reads **Waiting**, with its `Background:` line, until every command it started since its last prompt from you or the deck has ended. Such a turn also no longer clears the **Needs you** mark that an agent card's waiting, done or failed report raised. Both the TUI and the desktop app show the change. A turn OpenCode starts by itself in the same way still counts as a new turn; see [Work left running after a turn](https://agent-deck.devopstoolkit.ai/docs/session-management.md#work-left-running-after-a-turn).
