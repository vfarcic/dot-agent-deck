## Stop any daemon from its Dashboard section, remote ones included

Each daemon's section on the desktop Dashboard now has a **Stop daemon** button, whichever daemon the **Daemon** selector shows. It stops that daemon on this machine or on a remote host, after a confirmation that names where it runs and how many agents it reports. While agents are running there, the stop is refused and everything keeps running. Close the agents first, then press it again. A remote daemon whose release is too old to be stopped from the app shows the button greyed out and says so; stop it with `dot-agent-deck daemon stop` on its machine, or upgrade it.

When the daemon on this machine shows **Incompatible daemon**, its Dashboard section now offers **Replace daemon** too, with the same confirmation as before, so you no longer have to select it and open the Daemons screen first. See [Stop a daemon](https://agent-deck.devopstoolkit.ai/docs/desktop/daemons.md#stop-a-daemon).
