## Small-terminal dialogs act only on choices you can see

In a very small terminal, three TUI dialogs could act on a key whose choice was cut off the screen: `y` in the Schedules manager deleted a schedule whose delete question was not shown, `s` starred the repository while the star prompt's `s Star  l Later  d Don't ask again` line was hidden, and the directory picker could open or pick a directory it had not drawn. Those keys now do nothing until their choice is on screen, as in the Quit, Close, Stop and configuration confirmations, so enlarge the terminal to answer them. Escape still cancels each dialog.

A key typed before the delete question or the star prompt has appeared is also ignored, so wait for the question to show before you answer it.
