## Pi agents show their prompt and the tools they run

A Pi agent's card (TUI) or row (desktop app) now fills in the way Claude Code, Codex, OpenCode and Devin agents do. The prompt you submit appears as the turn starts (`Prmt:` on a TUI card). While Pi runs a tool, the agent shows that tool and its command or path (the TUI card reads **Working**), and each finished tool adds to its tool count. Once the turn settles, the agent keeps its directory, the prompt and its recent tool calls. Before, a Pi agent showed only its status and a tool count of 0, even after Pi visibly ran a shell command in its pane. Nothing needs to be set up: the deck's Pi extension reports all of this on its own.
