## Installation says when the OpenCode plugin is refreshed

The Agent hooks section of the installation page now says that the deck rewrites the OpenCode plugin every time it starts an OpenCode agent, not only when the TUI or the daemon starts. That includes an agent a scheduled task starts with no TUI open, so an OpenCode you set up after the deck started, or a plugin that still names a copy of the deck you have deleted, is fixed when the agent starts, without restarting the deck.
