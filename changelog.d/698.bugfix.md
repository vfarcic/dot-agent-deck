## No Stray Card for a Pane Whose Agents Are Gone

A hook report that names a pane but no agent, such as one from an older hook script, no longer adds a card for a pane the deck has finished with. The deck now treats these reports by the same rule as reports that name their agent. A pane that was reused by a second agent, which was then closed, has no agent left to report for it, so its stray reports are ignored. A pane whose only agent has just exited, with nothing started there since, still receives that agent's last status report, so its card still clears normally.
