## Switch deck by voice in the desktop app

Saying "switch deck to the build box" or "change the deck to local" now switches the deck the desktop app shows, exactly as choosing it from the Deck selector at the top does. It works on the deck and overview screens, the two that carry the selector, and reaches any deck the selector lists, including one the app is not connected to yet. Switching to the deck already shown says so and changes nothing, and a deck name that matches nothing or several decks is answered in words rather than ignored. Voice switches only to a deck you actually named — if it did not catch one, it says so instead of guessing — and if that deck's address is changed in Settings while the command is being understood, it asks you to say it again rather than connecting somewhere else.

While the New agent dialog is open, naming a deck still chooses the dialog's deck instead of switching, since the selector cannot be clicked behind the dialog. All Decks is not a voice target: it is a view over every deck rather than a deck.
