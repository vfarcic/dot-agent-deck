The `deck.instructions.commit` telemetry attribute now changes only when `CLAUDE.md`, `AGENTS.md` or a Markdown file under `.claude/skills` changes. A commit that touches only a script or a tool version pinned beside a skill no longer gives runs a new value, so comparing runs before and after an instructions change compares instructions an agent actually reads. `deck.telemetry.schema_version` is now `4`, so you can keep data recorded before and after this change apart.
