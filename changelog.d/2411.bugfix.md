## The desktop app shows the same status words as the TUI

The desktop Dashboard's table showed **Running** for an agent the TUI, the cards and the dashboard filter showed as Thinking, Working or Compacting, and **Failed** for one they showed as Error. The table, the counts beside each daemon and group, the agent's tile and its output reader now show the same word the TUI shows, so an agent reads the same wherever you look. The counters at the top of the Dashboard count **WORKING**, **THINKING**, **COMPACTING** and **ERROR** in place of **RUNNING** and **FAILED**, and the counters button reads `1 error` where it read `1 failed`. An agent that has reported no status yet still reads **running** in the table and on its tile, and the counters count it only under **AGENTS**.
