## Telemetry says which skill an agent loaded

With [telemetry](https://agent-deck.devopstoolkit.ai/docs/telemetry.md) on, each time Claude Code or OpenCode loads a skill, the agent's run gets a `deck.skill` event, and the run's `deck.skills.count` says how many it loaded. The event names the skill in `deck.skill.name` when the skill is defined in a skill directory on your machine, such as your project's `.claude/skills/<name>/` or your own `~/.claude/skills/<name>/`, so you can see which of your skills run and which never do. Claude Code's own telemetry names every project skill `custom_skill`. The skill's arguments are never sent, and neither is a name that no skill directory defines. A skill name is a directory name you or a project chose, so it is sent as written, like your orchestration and role names; [Trim what is sent](https://agent-deck.devopstoolkit.ai/docs/telemetry.md#trim-what-is-sent) shows how to drop it. Codex and Pi load a skill by reading its file, so their runs have no `deck.skill` events.
