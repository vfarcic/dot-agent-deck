## Send agent-run telemetry to an OpenTelemetry backend

The deck can now send a record of every agent run to an OpenTelemetry backend of your choice, such as Honeycomb's free plan: which agent ran in which pane, its role and orchestration, how long it spent in each status, when you typed into it, which pull request it opened, and how the run ended. Over time that answers questions such as which agent finishes a kind of task with the least help from you, or whether a change to your `CLAUDE.md` or skills helped. Several machines can send to one backend and are told apart by their host name.

It is off unless you set an endpoint with the standard variables, for example `OTEL_EXPORTER_OTLP_ENDPOINT` and `OTEL_EXPORTER_OTLP_HEADERS`, in the environment the daemon starts with; without one, nothing is sent and nothing changes. It works the same from the TUI and the desktop app. The deck sends metadata only: never prompts, file contents, agent output, tool-call arguments, your API key or other environment values, pane titles, branch names, paths or command lines. The only values it sends exactly as you wrote them are your own `OTEL_SERVICE_NAME` and `OTEL_RESOURCE_ATTRIBUTES`, so keep secrets out of those. It sends over HTTP to a backend whose certificate your system trusts, retries a busy or unreachable backend until the export timeout, and does not follow redirects; client certificates (mutual TLS) are not supported, and the page shows how to reach such a backend through a local OpenTelemetry Collector.

The agents the deck starts get the same configuration with the run's id added, so an agent's own telemetry can be joined to the deck's run in the backend. For Claude Code, when `OTEL_EXPORTER_OTLP_ENDPOINT` (or the metrics or logs endpoint of its own) is set, the deck also turns on Claude Code's own metrics and events unless you have set those switches yourself, and never turns on its prompt or tool-detail logging; set `CLAUDE_CODE_ENABLE_TELEMETRY=0` to keep them off. OpenCode joins with its own logs and traces; for Codex, Devin and Pi the page says what joins and what does not. The model, exit code, issue and invoking skill of a run are not sent yet.

See [Telemetry](https://agent-deck.devopstoolkit.ai/docs/telemetry.md).
