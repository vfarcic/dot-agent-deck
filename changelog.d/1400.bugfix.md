## Desktop agent pane shows only what works

The desktop app's agent pane no longer offers controls and readings that stayed empty against a real daemon. Its **Diff**, **Checks**, **Delegations** and **Artifacts** tabs, and its **ATT**, **MODEL** and **USAGE** fields, are hidden, so **Terminal** is the pane's only tab. They come back when the `experimental` flag is on (`DOT_AGENT_DECK_EXPERIMENTAL=1`).

**TIME** now shows how long the agent has been running, for example `5m` or `2h`, and keeps counting while the pane is open. Hover it to see the exact time the agent started. Before this change it always read `—`.

See [Dashboard → The agent pane](https://agent-deck.devopstoolkit.ai/docs/desktop/dashboard#the-agent-pane).
