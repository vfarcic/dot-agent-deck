## A Natural Exit Stays `exited` When Its Pane Is Closed Afterwards

With telemetry on, an agent that exited by itself is now recorded with `deck.run.end_reason` set to `exited`, and with its `deck.run.exit_code`, when you close its pane just after the exit. Before, a close that came right after the agent exited could record the run as `closed`, with no exit code. See [Telemetry](https://agent-deck.devopstoolkit.ai/docs/telemetry.md) for the attributes each run carries.
