Agent cards in the desktop app can send one action to many agents at once: from a card with agents under it (it reaches every agent under that card) or from a selection of cards, where selecting a closed card selects everything under it. Every batch opens a confirmation first that lists each agent that gets the action with the exact text it will receive, and each agent that is skipped and why; after **Send** it shows what happened for each agent, and one agent failing does not stop the others. Each delivery is recorded on that agent's own card. By voice, "go ahead on everything under the dispatcher" opens the same confirmation, and "select the coder's card" followed by "go ahead on the selected agents" opens it for a selection built by voice. Needs a daemon from this release.
