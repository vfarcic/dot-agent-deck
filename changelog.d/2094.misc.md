## Claude Code's prompt suggestions are off in agent-driven panes

Claude Code suggests your next prompt after each turn, and each suggestion costs an extra model request. An orchestration's worker panes and a single-agent unit started by `dispatch` take their work from the orchestrator or from their task rather than from you, so a suggestion there guesses at a prompt you are not writing. The deck now starts Claude Code there with `CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=false`. The orchestrator, a dispatcher and the panes you open yourself keep whatever you set in Claude Code. Your Claude Code settings file is left unchanged. The change is the same in the TUI and the desktop app, and other agents start as before.

See [Prompt suggestions are off in workers](https://agent-deck.devopstoolkit.ai/docs/orchestration.md#prompt-suggestions-are-off-in-workers).
