## Claude Code's prompt suggestions are off where nobody types

Claude Code suggests your next prompt after each turn, and each suggestion costs an extra model request. In an orchestration's worker panes and in a single-agent unit started by `dispatch`, nobody types, so those suggestions were never used. The deck now starts Claude Code there with `CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=false`. The orchestrator, a dispatcher and the panes you open yourself keep whatever you set in Claude Code. Your Claude Code settings file is left unchanged. The change is the same in the TUI and the desktop app, and other agents start as before.

See [Prompt suggestions are off in workers](https://agent-deck.devopstoolkit.ai/docs/orchestration.md#prompt-suggestions-are-off-in-workers).
