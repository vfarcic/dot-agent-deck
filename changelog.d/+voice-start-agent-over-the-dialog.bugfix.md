## Voice: "Start agent" with the New agent dialog open starts the agent

In the desktop app, saying "Start agent" while the New agent dialog's form is filled in starts the agent, as pressing its Start button does. Often it answered "Not here — the New agent dialog opens from the agent dashboard, when it is not already open." and started nothing. Saying "start it" or "start the new agent" with the dialog closed opens the dialog, where it occasionally answered that nothing asked to stop an agent, or that nothing matched.

See [Voice](https://agent-deck.devopstoolkit.ai/docs/desktop/voice.md).
