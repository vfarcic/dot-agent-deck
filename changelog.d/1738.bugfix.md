## TLS Library Updated for Four Security Advisories

The TLS library the deck uses for its HTTPS connections, `rustls`, is updated from 0.23.45 to 0.23.46, which fixes four advisories published against it: RUSTSEC-2026-0346 (debug output of a client session could expose TLS secrets), RUSTSEC-2026-0347, RUSTSEC-2026-0348 and RUSTSEC-2026-0349. All four are rated low or medium. Nothing changes in how you use or configure the deck.
