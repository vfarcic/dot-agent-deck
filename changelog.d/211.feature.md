## Antigravity CLI is a supported agent

Google's Antigravity CLI (`agy`), the successor to Gemini CLI, now runs in the deck like the other agents. Start it with `agy` as an agent's command, or from a shell in a pane, in the TUI or the desktop app, and it gets its own Antigravity badge and type filter. Its card follows what it is doing: **Thinking**, **Working** with the tool it runs, **Needs Input** while it waits for a permission, a sign-in or a folder-trust answer, **Error** when a turn fails, and **Idle** when a turn ends or you interrupt it. Beside **Needs Input** and **Error** the card shows `agy`'s own words, such as the command it asks to run. You can answer its permission prompts to run a command or write a file from the deck, by voice in the desktop app too; the deck sends an answer only while the pane shows that prompt, and a command it cannot show whole, such as one running over several lines, can only be denied from the deck. The voice commands to interrupt it, clear its prompt and scratch what you dictated work for it as they do for other agents, and reading mode announces its turn summaries. Antigravity support is experimental: the first time you start it from the new-agent form, and about once every 100 starts after, a dialog asks you to report a problem or let us know it works, and **Don't show again** turns it off in both the TUI and the desktop app.

Antigravity can take any role in an orchestration: delegated tasks reach it, including before its first prompt, and it reports them done with `work-done`. The deck types its doorbell into an idle `agy`, and `doorbell.antigravity` (or `DOT_AGENT_DECK_DOORBELL_ANTIGRAVITY`) turns that off. Declare `agent = "agy"` on a role whose command runs `agy` through a launcher.

The daemon installs one `dot-agent-deck` hook into `~/.gemini/config/hooks.json` when it starts with `agy` on its `PATH`, and again before it starts an Antigravity agent whose hook is missing or calls a deleted copy of the deck, keeping your other hooks there; `dot-agent-deck hooks install --agent antigravity` and `hooks uninstall --agent antigravity` do it by hand. The hook does nothing in an `agy` started outside the deck. Install `agy` and sign in once by running it yourself: the deck does not sign in for you. Google's FAQ says that wrapping `agy` in third-party applications is not supported under consumer plans; the installation page links it so you can decide which sign-in to use. See [Antigravity CLI](https://agent-deck.devopstoolkit.ai/docs/installation.md#antigravity-cli).
