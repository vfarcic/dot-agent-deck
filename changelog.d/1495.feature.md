## Name an agent by voice the way you think of it

In the desktop app you no longer have to say an agent's exact name. Name it by its mode ("select dispatcher agent"), its agent type ("the Codex agent"), its directory ("the agent in billing"), its orchestration ("the reviewer in the PRD 1487 orchestration"), the daemon it is on, what it was last asked to do ("the one fixing the scroll") or when it started ("the newest agent"), or combine them ("the newest reviewer"). A name shown on screen still wins: "open tester" opens the agent called tester.

"Select", "go to" and "switch to" now open an agent when you name an agent, and still switch the daemon when you name a daemon. When what you said fits several agents, the app lists them for you to choose from.

With **Names** shared, each agent's mode, type, directory name (never its full path), orchestration and the order the agents started in are now sent to the Commands service along with the other names on screen. When you name an agent by what it was last asked to do, the app compares your words with its prompt on your computer; prompts are not sent. See [Naming an agent](https://agent-deck.devopstoolkit.ai/docs/desktop/voice.md#naming-an-agent).
