## Reading follows the agent you are looking at

With Reading on in the desktop app, opening an agent's pane now narrows what is spoken to that one agent: its turn summaries, permission prompts, errors and usage limits. Nothing about any other agent is said while the pane is open, not even a permission prompt or an error, since their cards show **Needs Input**, **Error** or **Blocked** when you go back. Whatever was still waiting to be said about other agents when you opened the pane is dropped. Back on the dashboard, every agent is read again from that moment, and nothing skipped in the meantime is read out afterwards.

A sentence about an agent that is part of an orchestration now names the orchestration as well as the agent, using the title its group has on the dashboard: "Prd-1401 coder: all 42 tests pass." instead of "Coder: all 42 tests pass.". With several orchestrations running, you can tell their coders apart. A standalone agent is named as before.

See [Voice control → Reading](https://agent-deck.devopstoolkit.ai/docs/desktop/voice#what-is-read-where).
