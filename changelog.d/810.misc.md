## Test-Harness Credential Redaction Is an All-Match Search Instead of a Greedy Scan

`credential_redaction_ranges` — the function every credential-bearing test artifact passes through, including the `full-stream.cast` the demo reel publishes — was a greedy left-to-right scan with a single committed continuation chain. It had been point-fixed four times and a security audit still reproduced two leaks in it, both with fabricated values: a registered value whose start lay *inside* an earlier match survived, because the scan skipped every offset inside that match's first fragment; and a decoy continuation suppressed a real one, leaving the matcher redacting nothing at all. Both landed as failing tests first and are now closed.

What replaces it searches every registered value independently over the whole artifact, finds starts through an overlap-preserving multi-pattern index that walks every byte offset, and explores continuations as a deduplicated DAG over `(bytes consumed, cursor)` states, emitting ranges only from paths that reproduce the entire value. There is no cursor and no committed chain left for an ordering to go wrong in. That also restores **monotonicity** — adding a registered value can no longer remove a redaction, which matters because the artifact redaction set is a union of a per-deck set and a process-global one — and the property is asserted rather than argued.

The search now **fails closed** on all three of the things that can grow: a per-artifact step budget (a floor plus four steps per input byte, shared across the whole registered set), a bound on how much of the artifact the index may hold, and a bound on how much registered material may go into it — the last because credential collection accepts an unbounded number of values with no upper length limit. When any is exhausted the artifact is replaced whole with a `[WITHHELD-ARTIFACT: …]` notice rather than written with bytes nothing examined, and the step budget is charged inside the candidate enumeration so the refusal is prompt rather than eventual.

Cost, measured on the same build in the unoptimised profile the tests run in: the adversarial shape the audit flagged — 1.6 MB of repeated shared eight-byte prefixes — drops from **25.3 s to 2.3–2.7 s**. Two ordinary shapes got slower, and are stated rather than buried: a realistic 2.1 MB artifact holding one rendered credential document goes from 162 ms to 0.35–0.59 s (almost entirely the index's single pass, since the search on it is 51 steps), and a 2 MB artifact packed with that document every 140 bytes from 3.61 s to 5.5–6.0 s.

Redaction remains a best-effort blocklist: it can only remove values something registered, a run of credential bytes that sits on no complete path still survives, and fragments separated by something other than a row transition — or by more than the gap bound — are not bridged. What stands between a credential and a public URL is the demo reel's private-by-default upload plus a human's review, not this matcher.
