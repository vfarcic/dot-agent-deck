## A Delegated Task Left Unsent in a Busy Worker's Input Box Now Gets Submitted

On a heavily loaded machine, a delegated task could be typed into a worker's input box and never submitted, leaving the worker idle while the orchestrator waited for it. The deck now waits a moment for the task to show up in the worker's input box before pressing Enter, which on a machine that keeps up changes nothing you can see. If a task still ends up sitting unsent, the deck presses Enter for it again rather than typing it a second time.

See [A lost task is re-sent into the same worker](https://agent-deck.devopstoolkit.ai/docs/orchestration#a-lost-task-is-re-sent-into-the-same-worker).
