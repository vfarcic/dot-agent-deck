## The GPT agents move to `gpt-6-astra`

Every GPT-backed agent alias in `devbox.json`, plus opencode's own `agent.build.model` in `opencode.json`, now runs `gpt-6-astra` instead of `gpt-5.6-sol` and `gpt-5.5`. That covers the opencode roles (orchestrator, coder, reviewer, auditor, tester and the `oc-big` alias the dogfood config points at), the `codex-big` alias the `mixed` orchestration's tester uses, and the `pi` alias that runs against the OpenAI provider.

One alias is deliberately left behind: `oc-release` stays on `gpt-5.4-mini`. There is no `mini` in the astra family — the only variants published are `gpt-6-astra` and `gpt-6-astra-fast` — so moving it would put a role that was deliberately given a small cheap model onto a flagship one, which is a cost decision rather than a version bump.
