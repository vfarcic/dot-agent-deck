## macOS desktop bundles can be signed and notarized

The release workflow can now sign the macOS desktop `.dmg` with an Apple Developer ID and notarize it with Apple, which is what lets macOS open a downloaded app without the "damaged and can't be opened" dialog. Signing starts once the project's Apple signing credentials are configured. Until then the `.dmg` stays **unsigned**, as before, and each release's notes say whether its macOS build is signed and give the workaround only when it is not.
