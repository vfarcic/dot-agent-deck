## More reliable voice switching and dictation in the desktop app

"Switch deck to the build box" is no longer sometimes refused with "I did not catch which daemon" when your words name exactly one daemon. Dictating to an agent with an opening such as "tell it we should stop typing the logs to a file" types the words after "tell it" more reliably, where it sometimes typed nothing. See [Voice Control](https://agent-deck.devopstoolkit.ai/docs/desktop/voice).
