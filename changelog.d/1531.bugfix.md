## A New Agent in an Exited Worker's Pane Is No Longer Refused as Busy

When a delegated worker exited on its own before reporting and a different agent then took over its pane, `delegate` to that role was refused with "every worker it reached still owes a work-done" until the orchestrator passed `--supersede` or the new agent reported. The new agent was never given that task, so it is no longer counted against it: the delegate is sent without `--supersede`. A worker that is still running and owes a `work-done` is refused as before.
