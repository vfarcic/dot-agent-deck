## A Codex Command That Starts With an Assignment or a Shell Compound Now Starts

A Codex agent whose command begins with an environment assignment, such as `CODEX_PROFILE=work codex`, or with shell syntax such as `(umask 077; …); exec codex` or `cd project && codex`, failed to start: the pane showed an error about failing to spawn the assignment, or a shell syntax error. Such a command now starts, and is run by your shell exactly as you wrote it, the same way the commands of other agents are.
