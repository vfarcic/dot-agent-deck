## Choose the agent and command a dispatched unit runs

A single-agent unit started with `dot-agent-deck dispatch` used to run whatever its dispatcher ran, so a Claude Code dispatcher could only start Claude Code units, and starting a unit on another agent or model meant opening another dispatcher or opening the pane by hand.

`dispatch` now takes `--agent <name>` and `--command <cmd>`. `--agent opencode` starts the unit as OpenCode with its own command; `--command "devbox run oc-big" --agent opencode` starts it with that command, as OpenCode. The names are those a role's `agent = "…"` takes: `claude`, `opencode`, `pi`, `codex` and `devin`. `--agent` can be left out when the command starts with the agent's own program, as in `--command "opencode --model big"`. Either flag starts a single agent, cannot be combined with `--orchestration`, and leaves the task text, the worktree and the branch exactly as before. Ask a dispatcher pane for it in words, such as *"start that one on OpenCode"*, and it passes the flags for you.

A deck whose daemon is older than the CLI refuses these dispatches with a message saying nothing was dispatched, rather than starting the dispatcher's own command instead. Dispatches without the flags are unchanged.

See [Dispatcher Mode](https://agent-deck.devopstoolkit.ai/docs/dispatcher-mode.md#choose-the-agent-a-unit-runs).
