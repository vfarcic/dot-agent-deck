## One Deck List for the CLI and the Desktop App

The CLI and the desktop app now share one list of remote decks. A remote you add with `dot-agent-deck remote add` shows up in the desktop app, and a deck you add in the desktop app shows up in `remote list` and opens with `connect <name>`. Either one can edit or remove any deck, and neither overwrites the other's changes. Decks you added in an earlier desktop build move to the shared list the first time the new build starts, without duplicates and keeping the selected deck.

A deck added in the desktop app shows `unmanaged` as its version in `remote list` until `dot-agent-deck remote upgrade <name>` installs the binary. `connect` does not use a jump host set in the desktop app yet; add a `ProxyJump` line for that host to `~/.ssh/config` instead. Keep the CLI and the desktop app at the same version: an older CLI that changes the list drops the desktop app's extra details, and an older desktop build shows no remote decks once they have moved.

See [Remote environments](https://agent-deck.devopstoolkit.ai/docs/remote-environments#shared-with-the-desktop-app) for details.
