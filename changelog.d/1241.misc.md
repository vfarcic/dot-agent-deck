## The devbox OpenAI agent scripts now run on `gpt-6-sol`

The nine OpenAI-backed scripts in `devbox.json` (`agent-orchestrator-oc`, `agent-coder-oc`, `agent-reviewer-oc`, `agent-auditor-oc`, `agent-tester-oc`, `pi-sol`, `oc-big`, `oc-release` and `codex-big`) move from `gpt-5.6-sol`, `gpt-5.5` and `gpt-5.4-mini` to `gpt-6-sol`, which OpenAI positions for complex coding and agentic workflows. The two scripts that set a reasoning effort explicitly, `pi-sol` and `codex-big`, drop from `xhigh` to `high`. The Claude-backed scripts and `oc-kimi` are unchanged.

These are contributor convenience scripts only: the test model defaults, the desktop's command model and every workflow are untouched. OpenCode 1.18.32's model catalog does not yet list `gpt-6-sol`, so the OpenCode scripts may refuse to start until OpenCode catches up.
