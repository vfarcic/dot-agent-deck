## Dispatch no longer starts an orchestration it cannot brief

`dot-agent-deck dispatch --orchestration` used to spawn the whole team even when the coordinator context could not be published, handing the orchestrator the bare task text with no role template, no available-agents list and no delegation protocol. Nothing surfaced: the pane labels, the role cards and `daemon status` all looked exactly like a working team while five agents idled and the first one implemented the whole task by itself. The only trace was a single warning line in the daemon log.

That dispatch is now refused instead. The reply names the obstruction and the remedy — a `.dot-agent-deck` directory writable by group or other, a symlinked one, a context over the size limit, or an ordinary write failure — and because the context is composed before any role is started, nothing is spent: no agent runs, and the worktree and its branch are reclaimed so the dispatch name is free to retry once the directory is fixed.

Scheduled tasks and issue-dispatch are unaffected; they deliver their prompt verbatim and compose no context.
