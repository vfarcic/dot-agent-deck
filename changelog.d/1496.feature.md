## Filter the desktop dashboard, by click or by voice

The desktop app's agent dashboard can now show only the agents you care about. Type into **Filter agents** to match an agent's name, role, orchestration, working directory or last prompt, or press **Filter** to choose by kind (orchestration roles, single agents, or the dispatcher, schedule and schedule: issues modes), status (Working, Thinking, Waiting for input, Idle, Blocked, Error), agent type and daemon. While a filter is set, a line under the header says what it shows, for example `Showing 4 of 11 agents · Working · Dispatchers`, each part can be removed on its own, and **Show all** clears it in one click. The header's counters still count the whole fleet, and a daemon or group with nothing matching says so in one line. The filter lasts until you clear it or quit the app.

By voice, say "show only the dispatchers", "show me all working agents", "show Codex agents" or "show the agents on build box". "Show everything", "show all agents", "clear the filter", "remove the filter" and "reset" clear the filter and show the whole dashboard from any screen; with no filter set, "show everything" opens the dashboard as before. "Open tester" still opens one agent's pane. See [Filter the dashboard](https://agent-deck.devopstoolkit.ai/docs/desktop/dashboard.md#filter-the-dashboard).
