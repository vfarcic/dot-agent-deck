## The Desktop App Brings an Older Daemon on This Machine Up to Its Version

After you update the desktop app, the daemon on this machine no longer keeps running the older release until something else restarts it. When the app finds that daemon running an older release than its own, at start or while it is open, it restarts the daemon onto the version that came with the app, as the TUI does when it starts. The restarted daemon sets up the agent hooks again, as every daemon start does.

With nothing running on the daemon, the app restarts it without asking: the **Upgrade** dialog shows its progress and ends with both versions, for example `The daemon on this machine now runs 0.47.0 (it was 0.46.0).` With agents or orchestration roles running, the dialog lists every one a restart would stop and asks, with the same choices as upgrading a remote daemon: **Restart now** stops exactly those, and **Keep current daemon**, the default, stops nothing. The app asks once per daemon version while it is open. To do it later, press **Upgrade** on the **Local daemon** section of the Dashboard. A daemon from a release before 0.46.0 is restarted only when nothing is running on it.

Update the CLI along with the app: a TUI from an older CLI restarts the daemon onto its own older version when it starts.

See [Daemons → Upgrade the daemon on this machine](https://agent-deck.devopstoolkit.ai/docs/desktop/daemons.md#upgrade-the-daemon-on-this-machine).
