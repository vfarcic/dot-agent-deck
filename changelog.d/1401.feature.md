## Pull Requests on the Dashboard

When an agent works on a branch that has a pull request on GitHub, the deck now shows it, so you can see at a glance which agents have opened one and where each stands, without leaving the deck. The badge appears by itself and follows the pull request: its number, its state (open, draft, merged or closed) and its review (approved, changes requested or review required), updated within about a minute of a change on GitHub.

In the TUI the badge sits on the agent's card, as `#1234` with a glyph for the state and one for the review, and `o` opens the selected card's pull request in your system browser; where no browser can open, as in a TUI on a remote host, the status line shows the pull request's address for you to copy instead. In the desktop app the badge is on the agent's row and in its pane, and clicking it, or saying "open the PR" with voice on, opens GitHub's own page for it inside the app, with **Back**, **Open in browser** and **Close** above it and `Escape` to close it. By voice you can also scroll the page, say "open it in the browser" or "close". Links to other sites open in your system browser. The page keeps its own GitHub sign-in across restarts, and **Settings → GitHub → Sign out of GitHub** ends it; a sign-in through SAML single sign-on, Google or Apple leaves GitHub and has to be done in the system browser instead.

The badge needs a daemon from this release, and GitHub's `gh` command installed and signed in on the machine where the agents run, which for a remote is the host.

See [Dashboard → Pull requests](https://agent-deck.devopstoolkit.ai/docs/desktop/dashboard.md#pull-requests) and [Session Management → Pull request badge](https://agent-deck.devopstoolkit.ai/docs/session-management.md#pull-request-badge).
