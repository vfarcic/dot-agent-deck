## Renamed Deck Builds Wrap Codex With Themselves

A deck binary run under a file name other than `dot-agent-deck` — a release asset run as downloaded, such as `dot-agent-deck-linux-amd64`, or any build you renamed — now launches Wrapper-strategy agents (Codex) through its own executable. Previously such a build rejected itself by name and handed the wrapper role to a different `dot-agent-deck` sitting next to it, or to whichever one `$PATH` found, so the agent pane could be monitored by another version of the deck without any error or log line.

Nothing needs to be configured; a build installed as `dot-agent-deck` behaves as before.
