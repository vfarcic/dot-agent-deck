## Interrupted work: see and clean up what a deck restart left behind

You can now pick up, clean up and read what a deck daemon restart left behind. **Interrupted work** lists the units a dispatcher started, the orchestrations, the scheduled issue dispatches and the agents you opened yourself that a restart stopped, with each item's branch, worktree, who started it, how far it got, the worktree's Git and pull request state, and the reports nobody received, each with the date the deck deletes it. A report whose orchestrator or dispatcher is gone is listed with the work that sent it even when no restart happened.

In the TUI, a row above the footer says how many items there are, such as `3 interrupted items from before the restart`; press `I` to open the list and `X` to hide the row (both can be rebound in `keybindings.toml`). In the desktop app, each daemon with interrupted work shows the same words as a banner on the agent dashboard, `I` opens its dialog, and the restart notice in the corner says how many items there are, with a **Show** button. When the deck could not read its whole work journal and lists nothing, the TUI's row and the desktop banner say some interrupted work may not be listed, so you can still open the list. By voice, say "show interrupted work", "reclaim the first one", "dismiss the second one" or "dismiss all". From a shell, use `dot-agent-deck interrupted list`, `show <id>`, `reclaim <id>` and `dismiss <id>…` or `dismiss --all`; `list --no-git` skips the Git and pull request facts and `--json` prints the list for a script.

**Reclaim** removes an item's worktree, including the files Git ignores there, and keeps its branch, after showing what it would do. It keeps a worktree that has uncommitted changes or other worktrees or Git checkouts inside it, and says why; commits on no remote are counted and reported, and the branch keeps them. **Dismiss** and **Dismiss all** take items off the list for good, leaving their worktrees, branches and reports alone. Agents can list interrupted work but not reclaim or dismiss it. `close <unit>` after a restart now points at `dot-agent-deck interrupted list`, and so does `work-done` when it saves a report for an orchestrator that is gone.

The list needs a daemon from this release. After upgrading, finish or stop the agents the running daemon has, stop it with `dot-agent-deck daemon restart`, then start the new one by opening the TUI or pressing **Start daemon** in the desktop app (or `dot-agent-deck daemon serve` for a daemon you run yourself).

See [Interrupted Work](https://agent-deck.devopstoolkit.ai/docs/interrupted-work).
