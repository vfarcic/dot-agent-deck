## Shell Spans Say When the Deck Ended Them

An `agent.operation` span now carries `deck.operation.end` when the deck ended it itself, before the agent reported the command's end, so its duration is not how long the command ran. Until now such a span looked like any other, and a single command that failed in Claude Code could add hours to a sum of shell time.

The value is `run_end` for a command still open when its run ended, and `cap` for the oldest of 64 open commands, ended when the agent started another. The attribute is absent when the agent reported the end itself. To sum the time agents spend in commands without them, filter with `deck.operation.end does-not-exist`. Spans that can end this way include a command that failed in Claude Code, a `bash` call that throws in OpenCode (for example one whose permission you rejected), and a shell call you interrupted in Codex.

See [Telemetry](https://agent-deck.devopstoolkit.ai/docs/telemetry.md#agentoperation) for the attribute and the example query.
