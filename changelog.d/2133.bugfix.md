## Claude Code: a message sent while it works waits for its turn to end

A deck message that reaches a Claude Code agent while it is in the middle of a turn, for example one you started by typing a prompt, now waits until that turn ends and arrives as a task of its own. Before, Claude Code could receive it in the middle of the other work, and the agent sometimes finished that work without acting on the message, while the card did not show it as taken. If the turn is still running after about a minute, the deck hands the message over anyway.

The deck also no longer types its doorbell line into a Claude Code agent's input box just as the agent is waking up for an earlier message. That line could stay in the input box and be sent together with the next prompt you typed.
