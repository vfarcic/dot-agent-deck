## A late-starting agent's first prompt waits for its input to be ready

When an agent pane gives no readiness signal within 10 seconds (opencode's cold boot, or a launcher that starts the real agent late), the deck types the mode's seed prompt or the orchestrator's role prompt anyway. That fallback now waits the same short readiness pause (500 ms) the deck already waits after an agent does signal readiness, instead of typing immediately. An agent still setting up its input at the 10-second mark is less likely to receive the prompt as text in its input box that never submits. The prompt arrives about half a second later than before in that case; agents that do signal readiness are unaffected.
