## Worker-failure reports mark the worker's pane name as untrusted

When a delegated worker exits without reporting, never comes up, fails to restart, or is blocked by a provider usage limit, the report the deck sends to the orchestrator names the worker's pane. In an orchestration that pane name includes the orchestration's name from `.dot-agent-deck.toml`, so a cloned project could make its own words read as part of the deck's report. The pane name now arrives marked as untrusted text copied from project config, the way role names already are in the deck's other reports, so the orchestrator reads it as a name only.
