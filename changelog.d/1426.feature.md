## Daemon Names in the Desktop App

The desktop app now shows each remote daemon by its name, the same name `dot-agent-deck connect <name>` takes, in the daemon selector, in Settings → Daemons, on the Dashboard and in its notices. Settings → Daemons shows the daemon's address beside its name, and a daemon with no usable name is still shown by its address.

You choose the name when you add a daemon in Settings → Daemons. The **Deck name** field starts with a suggestion based on the host, so you can keep it or type your own. You can also rename a daemon you already added: choose it, change **Deck name** and press **Rename**. The CLI sees the new name straight away in `remote list` and `connect`, and a name set with the CLI shows up in the desktop app. A name the app cannot use, such as one another daemon already has, is refused with the reason under the field. With voice Names shared, a remote daemon is sent to the Commands endpoint by its name; a daemon with no usable name is sent by its ssh user, host and any non-default port instead.

One change to how adding works: a new daemon is no longer saved as soon as its address is valid. Fill in its fields and press **Add this daemon** to add it.

See [Daemons](https://agent-deck.devopstoolkit.ai/docs/desktop/daemons) for details.
