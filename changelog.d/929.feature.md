## A restored orchestration starts only the roles you had running

When the deck recreates your workspace after its agents are gone (a reboot, a fresh machine, or a stopped daemon), an orchestration tab now starts only the roles that had a pane when the workspace was last saved. A role whose pane you had closed comes back as an empty card with nothing running in it, instead of being started again. To start it, have the orchestrator run `dot-agent-deck pane spawn <role>`. A `delegate` that reaches no worker because the role's pane was closed now says so and names `pane spawn <role>`. A workspace saved by an earlier version of the deck still starts every role. Reattaching to agents that are still running is unchanged.

See [Session Management → Orchestration tabs come back too](https://agent-deck.devopstoolkit.ai/docs/session-management.md#orchestration-tabs-come-back-too).
