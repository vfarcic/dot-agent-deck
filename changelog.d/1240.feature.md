## Hidden, Symlinked and Crowded Directories in the Desktop's New Agent Browser

The desktop's New agent directory browser can now reach three kinds of directory it could not before: hidden ones, symlinked ones, and ones past the deck's 1000-entry listing limit. Since the typed-path field was removed, browsing has been the only way to choose where an agent starts, so these directories could not be chosen at all.

A **Show hidden** checkbox beside the filter lists `.`-named directories such as `.config`. You can also press `.` in the directory list. A symlink to a directory now appears with a **link** tag. Opening it lists the directory it leads to, and an agent started there runs in that real directory. When a directory holds more subdirectories than the deck lists at once, the browser says so. Typing a filter then asks the deck to search the whole directory rather than only the entries it returned, so a directory whose name sorts past the limit can still be found and chosen.

These controls appear on decks at this release or later. A deck from an earlier release is browsed as before, without Show hidden, link rows or a deck-side search.
