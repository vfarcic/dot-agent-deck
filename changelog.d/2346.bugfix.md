## A deck message Codex dropped is no longer marked delivered

When the deck handed a message to Codex through its prompt hook or at the end of a turn, it counted the message delivered as soon as its own hook had written it. If you interrupted Codex (Esc) at that moment, Codex dropped what the hook gave it, yet the deck showed the message acknowledged and never sent it again.

The deck now counts such a message delivered only once Codex's session log shows that Codex took it. A message Codex dropped stays undelivered and is handed over again, marked as a possible repeat. If another of your `UserPromptSubmit` hooks blocks the prompt carrying a message, Codex keeps the message and the agent sees it on its next turn, so the deck counts it delivered. Nothing needs to be configured.
