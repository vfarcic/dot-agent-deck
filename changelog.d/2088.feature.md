## Telemetry says why a shell command has no program

With telemetry on, an `agent.operation` span that the deck records without `deck.operation.program` now carries `deck.operation.declined`, saying why: for example `argument_syntax` for `grep "x" file`, `setup_syntax` for `cd "$DIR" && cargo test`, `shell_grammar` for a `for` loop, or `codex_prefix` for a Codex command run under `sudo`. When a word's shell syntax was the reason, `deck.operation.declined.syntax` says what kind it was, such as `quote`, `variable`, `heredoc` or `redirection`. Group by the two to see which kinds of command your agents run that go unnamed. Both are values from a fixed list the deck chooses from, so they send nothing of the command itself, and a span that names its program carries neither. See [Why a command has no program](https://agent-deck.devopstoolkit.ai/docs/telemetry.md#why-a-command-has-no-program).
