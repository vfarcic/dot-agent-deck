## Docs Your Agent Can Read, and a New Website

The website at [agent-deck.devopstoolkit.ai](https://agent-deck.devopstoolkit.ai) is now a single landing page: what Agent Deck is, what it looks like running, where it runs, and a prompt you can paste into your AI agent so it installs and sets up the deck for you. If you would rather install it yourself, the page links to the installation guide. The docs behind it are now plain Markdown at stable addresses, such as [getting-started.md](https://agent-deck.devopstoolkit.ai/docs/getting-started.md), so an agent can fetch and read them directly.

Two files give an agent the whole set: [llms.txt](https://agent-deck.devopstoolkit.ai/llms.txt) lists every page with a one-line description, and [llms-full.txt](https://agent-deck.devopstoolkit.ai/llms-full.txt) holds all of them in one file. Links to the old documentation pages, including those in earlier release notes, redirect to the page that replaced them.

`dot-agent-deck docs` prints the documentation for the version you have installed, without network access. With no argument it lists the topics; `dot-agent-deck docs <topic>` prints one page (for example `dot-agent-deck docs orchestration` or `dot-agent-deck docs desktop/voice`), and `dot-agent-deck docs --all` prints every page. An unknown topic exits with an error and lists the valid ones. Because the website follows the latest release, this is the version to point your agent at when your installed deck is older.

The docs themselves were rewritten for an agent working on your behalf: each task gives the exact commands and configuration and says how to check that it worked, the pages carry reference tables for configuration keys, orchestration roles, schedules and command-line flags, and the common failures say how they show up and what to do. One correction is worth knowing if you write schedules by hand: in a cron expression, numeric days of the week count from `1` = Sunday to `7` = Saturday, and `0` is rejected, which differs from standard cron. The docs did not say so before. Day names (`MON-FRI`) avoid the difference.
