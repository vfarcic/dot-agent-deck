## Messages reach Codex sooner after its pane is resized

When you typed into a Codex agent's input box and emptied it, and then resized its pane a few times in quick succession, a message sent to that agent waited about 36 seconds before the deck checked the box and handed the message over. This happened when only the TUI was showing the pane. Nothing was typed into the box during the wait, but the message sat queued and the card said `the deck can't check this agent's input box` for most of it.

The deck now checks the box as soon as Codex has finished redrawing for the new size, so the same message is handed over in about 6 seconds. If Codex keeps redrawing, for example while a pane is being resized continuously, the deck still waits longer between checks as before.

See [How the deck checks Codex's input box](https://agent-deck.devopstoolkit.ai/docs/orchestration.md#how-the-deck-checks-codexs-input-box).
