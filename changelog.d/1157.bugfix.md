## The desktop app now installs Claude Code hooks and the OpenCode plugin without a CLI install

Hooks were meant to be auto-installed on every startup. For Claude Code and OpenCode, though, that only happened when the dashboard started. The desktop app never starts the dashboard: it starts the background daemon bundled inside it. So on a machine with the desktop app and no CLI deck installed, Claude Code and OpenCode agents never got the deck's hooks, and the deck received none of the status, tool and prompt events those hooks carry. Codex and Devin were not affected, because the daemon already installed theirs.

The daemon now runs the same startup auto-install as the dashboard, for all four agents. Where there is no CLI install to point at, the hooks name the daemon bundled in the app. Nothing needs configuring: start the desktop app and the hooks are written.

See [Troubleshooting → Hooks](https://agent-deck.devopstoolkit.ai/docs/troubleshooting#hooks).
