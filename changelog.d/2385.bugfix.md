## A Claude Code agent whose turn ended on an API error is woken by its next message

When a Claude Code turn ended on an API error, such as an overloaded API, the agent was not woken by the messages that reached it afterwards. An orchestrator idle after such a turn kept its workers' reports unread until you typed into its pane.

Such an agent now takes its next message on its own, as it does after a turn that ended normally, in the TUI and in the desktop app. This needs Claude Code 2.1.328 or newer, started after you upgrade the deck. After a usage or credit limit (a **Blocked** card), the agent's messages still wait until it works again.
