## The desktop app says "daemon" for a daemon everywhere

A few places in the desktop app still called a configured daemon a "deck", although the rest of the app says "daemon". They now say daemon too.

The add-a-daemon form, in **Settings → Daemons** and in the Dashboard's **Add a daemon** dialog, labels its name field **Daemon name** (it was **Deck name**). It still takes the name that `dot-agent-deck connect <name>` uses. The rename messages now say "That daemon is no longer listed.", "A daemon named '…' already exists." and "Invalid daemon name: …". The explanation of a refused name no longer says "deck name" in either client, so `dot-agent-deck remote add` reports, for example, `Invalid remote name: a name must start with an ASCII letter or digit.` The **Review project commands** dialog labels the daemon an approval is for as **Daemon:**. The messages shown when the selected daemon changes under a voice choice or an open review now say "daemon" as well, and so do the voice replies about answering an agent's question. Voice control still accepts "deck" when you say it.

See [Daemons](https://agent-deck.devopstoolkit.ai/docs/desktop/daemons.md) and [Approving project commands](https://agent-deck.devopstoolkit.ai/docs/project-trust.md).
