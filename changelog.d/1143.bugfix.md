## An open agent pane survives its deck going quiet, and says how old what it shows is

An agent pane in the desktop app stayed open when its deck stopped answering, but went blank instead of explaining itself. The explanation had been built — a sentence naming the deck and repeating that deck's own account of the failure, in place of a terminal that would only sit black — but it could never appear: a deck with no live link reports no agents, and every field the pane draws comes from the agent record such a deck no longer supplies.

The pane now keeps the last record its deck gave, for as long as that pane is open, so the header, the prompt, the tool and all five tabs are still there while the deck is away and the terminal's place carries the explanation it was always meant to. Nothing else on screen changes: the overview and the deck grid still list nothing for a deck that cannot vouch for what it is running.

Because that record was true at some past moment and may be arbitrarily old, the pane says so rather than asserting a status it cannot confirm. The status chip reads `last seen: running` instead of `running` and drops its live colour; the sentence beside the missing terminal names how long ago the deck last reported, with the exact instant on hover. The moment the deck answers again the terminal attaches under the same pane, the notice clears and the header goes back to reporting live state — no reopening, and no pane left hedging about an agent it is streaming.
