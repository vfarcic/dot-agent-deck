## Building from source needs Rust 1.99.1

Building dot-agent-deck from source, through `cargo install` or the Nix flake's overlay against your own nixpkgs, now needs Rust 1.99.1 or newer. Cargo stops an older toolchain before compiling and names the version it needs. Installing a prebuilt binary needs no Rust toolchain and is unaffected.

See [Installation](https://agent-deck.devopstoolkit.ai/docs/installation.md).
