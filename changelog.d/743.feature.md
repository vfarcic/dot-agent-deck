## Light and dark, following your machine

The desktop GUI follows your operating system's light/dark appearance. On a machine set to dark it now opens dark, with no configuration and no restart, instead of being a bright panel among dark windows.

Settings → Appearance carries the override: **System**, **Light** or **Dark**. System is the default and keeps following the OS live — change the appearance with the app open and the window follows. Light and Dark win over the machine in both directions, so a dark app on a light OS and a light app on a dark OS both work, and the choice persists across restarts. It is a global choice: previewing the browser fixture cannot reset the appearance of your real app.

Every surface the app has is covered — the deck, all four configuration sheets, the settings sheet, the command palette, the shortcut and confirmation dialogs, the connection banner and the failure and empty states — because getting here meant collapsing 150 hard-coded colours onto a named palette, so nothing is left behind holding a light value. The webview's own chrome follows too: scrollbars, form controls and the background behind the page.

**The agent terminals stay dark in both appearances, and that is deliberate.** Agent CLIs choose colours for a dark terminal — dim greys tuned to read on black, and truecolor output that bypasses the palette entirely — so a light pane would be unreadable in a way Agent Deck cannot fix from the outside. The chrome around the panes themes; the pane stays a dark inset, which is what it already looked like in light mode.

Light mode is otherwise unchanged from the previous release. One thing to know if you use it: `--faint` and `--muted`, the two dimmest text colours, do not meet WCAG AA on some surfaces, and they did not before this change either — the dark values were set to clear AA rather than mirroring that, so light is currently the weaker of the two on contrast. [#821](https://github.com/vfarcic/dot-agent-deck/issues/821) fixes it separately, so that the change that introduced dark mode could leave light mode provably untouched.
