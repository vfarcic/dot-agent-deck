## Turning on the daemon log from the desktop app

[Troubleshooting › Enabling Debug Logs](https://agent-deck.devopstoolkit.ai/docs/troubleshooting.md) now explains how to collect a log when you use the desktop app. The app writes no log of its own, so you start the daemon it connects to with `DOT_AGENT_DECK_LOG` (and `RUST_LOG` for more detail) set, from a terminal, then press **Reconnect**. The page gives the command for macOS and Linux and says where the file lands. It also explains that a daemon started by the app only has a log if the app itself was launched with the variable, which an app opened from the Dock, Finder or an application menu never is.

The page now also says that the daemon reads `DOT_AGENT_DECK_LOG` only when it starts, for TUI users too. A daemon that is already running has to be restarted before it logs anything. It also explains what the separate `daemon.log` file in the deck's state directory holds.
