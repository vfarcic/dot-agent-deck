## Readable desktop app text at 100% zoom

The desktop app's own text (labels, rows, buttons, dialogs, cards) is now sized from the agent output in its terminal panes, so it is readable at the default 100% zoom. Before, most of it was about 70% of the terminal's size, and zooming in could not fix that because zoom enlarges the terminal too.

Ordinary text is now at least the size of the agent output, headings are larger, and only secondary text such as badges, hints and key caps is a step smaller. The **Close agent** button in an agent pane's header now matches the controls beside it instead of being oversized. In a narrower window the Dashboard's header shows fewer counters, **WAITING**, **IDLE** and **GROUPS** first, to keep room for its buttons; widen the window or zoom out to bring them back.

See [The Dashboard](https://agent-deck.devopstoolkit.ai/docs/desktop/dashboard.md).
