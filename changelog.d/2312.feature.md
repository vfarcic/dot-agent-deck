## Readable desktop app text at 100% zoom

The desktop app's own text (labels, rows, buttons, dialogs, cards) is now sized from the agent output in its terminal panes, so it is readable at the default 100% zoom. Before, most of it was about 70% of the terminal's size, and zooming in could not fix that because zoom enlarges the terminal too.

Ordinary text is now at least the size of the agent output, headings are larger, and only secondary text such as badges, hints and key caps is a step smaller. The **Close agent** button in an agent pane's header now matches the controls beside it instead of being oversized.

The Dashboard's row of counters at the top is now one button. It shows the number of agents and, only when something needs you, how many need input, how many failed and how many daemons are not answering. Hover over it or click it to see every count, or say "show the counters" with voice on. A daemon with no agents now shows **No agents are running yet** as one line across its section, with its **New agent** button, instead of a large card, and that note no longer offers **Open daemons**, which opened the Daemons screen for whichever daemon was selected rather than that one; the button at the top of the Dashboard and the rail still lead there.

See [The Dashboard](https://agent-deck.devopstoolkit.ai/docs/desktop/dashboard.md).
