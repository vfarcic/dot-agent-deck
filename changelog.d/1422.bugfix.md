## Agent Keyboard Shortcuts Work the Same in the TUI and the Desktop App

In the desktop app's agent terminal, Shift+Enter and Ctrl+Enter used to reach the agent as a plain Enter, so they sent the message you were still writing. Shift+Enter now inserts a new line in every supported agent, as it does in the TUI. Ctrl+Enter now reaches the agent as Ctrl+Enter, as it does in the TUI, and each agent decides what it does: OpenCode inserts a new line, Claude Code sends the message right away, and Codex, Pi and Devin ignore it. Ctrl+J also inserts a new line in every supported agent. Ctrl+/ now reaches the agent too, where the desktop app used to send nothing for it.

Text-editing shortcuts now work in an agent's prompt, and do the same thing in both clients on every platform: `Home` / `End` and ⌘← / ⌘→ go to the start and end of the line, Ctrl+← / Ctrl+→ and Alt+← / Alt+→ (⌥← / ⌥→) move by a word, ⌘⌫ deletes to the start of the line, Ctrl+Backspace and Alt+Backspace (⌥⌫) delete the previous word, and Ctrl+Delete and Alt+Delete (⌥⌦) delete the next word. Outside a Mac, ⌘ is the Windows key; the desktop app on Linux cannot see the Super key, so there use `Home` and `End`. In the desktop app, ⌘← and ⌘→ used to do nothing, ⌘⌫ and Ctrl+Backspace deleted one character, and ⌥⌦ (Alt+Delete) made Claude Code delete everything after the cursor. On Windows, Ctrl+V now pastes in the desktop app, where it used to be typed into the agent. Paste follows the computer you are typing on, whatever machine the agent runs on.

In the TUI, Ctrl+Backspace, Ctrl+Delete and ⌘⌫ used to delete one character, ⌥⌦ deleted one character or typed `[3~` into the prompt, and ⌘← and ⌘→ moved one character. Alt+← and Alt+→ (⌥← and ⌥→ on a Mac) moved one character in Claude Code and Pi and typed `[D` or `[C` into the prompt in Codex and Devin. They now do what they do in the desktop app, whenever your terminal passes the key on to the TUI. Your terminal decides that: iTerm2, for one, switches tabs on ⌘← and ⌘→, and a terminal without the enhanced ("kitty") keyboard protocol sends Ctrl+Backspace as a one-character delete. [Editing an agent's prompt](https://agent-deck.devopstoolkit.ai/docs/keyboard-shortcuts.md#editing-an-agents-prompt) says how to set your terminal up for them.
