## Agent Keyboard Shortcuts Work in the Desktop App's Terminal

In the desktop app's agent terminal, Shift+Enter and Ctrl+Enter used to reach the agent as a plain Enter, so they sent the message you were still writing. Shift+Enter now inserts a new line in every supported agent, as it does in the TUI. Ctrl+Enter now reaches the agent as Ctrl+Enter, as it does in the TUI, and each agent decides what it does: OpenCode inserts a new line, Claude Code sends the message right away, and Codex, Pi and Devin ignore it. Ctrl+J also inserts a new line in every supported agent. Ctrl+/ now reaches the agent too, where the desktop app used to send nothing for it.

Your platform's usual text-editing shortcuts now work in an agent's prompt too. On macOS, ⌘← and ⌘→ go to the start and end of the line, where they used to do nothing; ⌘⌫ deletes to the start of the line, where it used to delete one character; and ⌥⌦ deletes the next word in every agent, where Claude Code used to delete everything after the cursor. On Windows and Linux, Ctrl+Backspace deletes the previous word, where it used to delete one character, and Ctrl+Delete deletes the next word in every agent, where Claude Code used to delete one character and Pi did nothing. On Windows, Ctrl+V now pastes, where it used to be typed into the agent. The app uses the shortcuts of the computer you are typing on, whatever machine the agent runs on.

See [Editing and pasting in an agent's prompt](https://agent-deck.devopstoolkit.ai/docs/desktop/settings#editing-and-pasting-in-an-agents-prompt), [Keys typed into an agent's terminal](https://agent-deck.devopstoolkit.ai/docs/desktop/settings#keys-typed-into-an-agents-terminal) and [Shift+Enter or Ctrl+Enter sends the message](https://agent-deck.devopstoolkit.ai/docs/troubleshooting#shiftenter-or-ctrlenter-sends-the-message).
