## `config set` keeps the rest of your configuration file

`dot-agent-deck config set` used to rewrite the whole configuration file from the settings it knows, removing your comments and every other table. It now changes only those settings and keeps the rest of the file as you wrote it, including an agent cards `[catalog]`. It also no longer replaces a file it cannot parse with the defaults: it refuses to save and says so, so fix the file and run it again. See [Configuration](https://agent-deck.devopstoolkit.ai/docs/configuration.md).
