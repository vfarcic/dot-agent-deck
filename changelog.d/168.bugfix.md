## New Agent Mode chips wrap instead of being cut off

In the TUI's New Agent form (`Ctrl+n`), a project with many or long orchestration names on a narrow terminal made the **Mode** row wider than the dialog, and the last chips, including the built-in `[schedule]` and `[dispatcher]` options, were cut off at the right border. The chips now wrap onto more rows and the dialog grows taller to fit them, so every mode stays visible and selectable. `←` / `→` and clicking a chip work the same on every row, and the Name and Command fields move down below the chips. The desktop app's New agent dialog already wrapped its Mode chips, so the two now behave the same.
