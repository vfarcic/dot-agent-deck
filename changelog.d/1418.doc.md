## Getting Started has install steps for the desktop app

The [Getting Started](https://agent-deck.devopstoolkit.ai/docs/getting-started) quick start used to give copy-paste install steps for the TUI only and a single link for the desktop app. It now has desktop steps of its own for an Apple silicon Mac and for Linux amd64 (Debian and Ubuntu): which file to download, how to check that it came from this project's release before installing it, how to install it and how to launch it, and a reminder that the app connects to a daemon the TUI runs. [Installation](https://agent-deck.devopstoolkit.ai/docs/installation#choose-an-install-method)'s table of install methods now lists the desktop app too.
