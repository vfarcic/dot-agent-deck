## The desktop Dashboard marks only the agents your typing cannot reach

The desktop app's Dashboard no longer puts a `WRITE` label next to an agent. Codex agents carried that label and Claude Code, OpenCode and Pi agents did not, although input typed in the app reaches all of them, so it read as the Codex agents having something the others lacked.

An agent whose input the app cannot deliver still carries a label: `READ` for one whose history the deck can show but not type into, and `NONE` for one it can only show. Hovering the label says why. This matches the TUI, whose card is unmarked when you can type into the agent and says `history` or `view-only` when you cannot.
