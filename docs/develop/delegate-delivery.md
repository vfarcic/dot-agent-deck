# Delegate delivery

Delegated tasks now use the per-agent inbox described in [Agent messaging](agent-messaging.md). A task is queued for the selected worker generation, fetched by its integration and acknowledged on that agent's receipt signal. The task-file pointer can be inside the message body; it is not typed into the worker's composer.

The inbox id replaces the old delivery id for acknowledgement and dedup. A hook event from an unrelated turn does not settle pending work. Redelivery preserves the message id, uses the inbox ack-wait and delivery limit, and leaves the worker process running. A recipient exit makes its bound messages undeliverable rather than moving them silently to a successor.

A newer delegation or a pane restart supersedes the worker's earlier unacknowledged tasks without reporting them. Completion is inferred because `work-done` carries no task id: if the worker acknowledged a task since its previous completion, the report answers that task and retires only later unacknowledged tasks fetched at least once. A newer task never fetched remains queued and watched for a delivery notice. If no task was acknowledged since the previous completion, the report is treated as answering work taken another way, such as from its task file, and retires every unacknowledged task to that pane. This preserves a newer queued task against one late completion of an acknowledged task. It does not preserve it against a worker that reports `work-done` twice, whose second report retires a newer task it never fetched; and an acknowledged task that is never completed makes the completion of a later task taken from its file leave that task queued. Both stay within the worker's own pane, and a `work-done` naming its task id, which is not implemented, would close them. See [Delegated-task retirement](agent-messaging.md#delegated-task-retirement).

The former echo-gated Enter, screen-based probe → grace → retype loop and provisional prompt confirmation are removed. Human typing and the guarded fixed doorbell remain PTY input. The doorbell guards and per-agent acknowledgement table live in the new guide.
